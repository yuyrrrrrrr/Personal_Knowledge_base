# Python 模块知识库规范

## 沟通语言

与我的所有自然语言交流使用简体中文。
命令、代码、路径使用英文原文并用反引号包裹。

## 文件编码

- 所有 Markdown 文件使用 UTF-8（无BOM）+ LF 行尾。
- Frontmatter 必须是文件的第一行内容，`---` 前不能有空行。

## 目录结构（保持现有架构）

本模块涉及两个文件夹，暂不合并：

- `1-Python Foundation/`     # 语法基础阶段
- `2-Python Advanced/`       # 进阶应用阶段

## 文件命名规范

- 章节笔记保持现有命名格式：`序号-英文标题.md`，如 `1-Python Basic Grammer.md`
- 序号即学习顺序，不可打乱
- Summary 文件改造为 `学习总结.md`，保留在各自文件夹中
- Canvas 文件保持现有命名，如 `Foundation Mind.canvas`

## Frontmatter 规范（每个章节笔记必须包含）

## 章节笔记内容规范（核心）

- 每篇笔记的第一段为 `## 本章大纲`，用 `[[#标题名]]` 锚点链接列出该章所有 `##` 级标题，方便快速跳转定位。
- 正文用 `##`、`###` 标题组织细节，小知识点放在标题下，不单独建文件。
- 章节笔记可以写得较长，内容要覆盖教程中该章节的全部知识点，按 CodeFather Python3 教程大纲组织。
- 章节笔记内部提到其他章节核心概念时，可加 `[[链接]]`，每篇不超过 3 个。

## 学习总结规范

- 每个文件夹一份 `学习总结.md`，汇总该阶段所有章节的核心要点。
- 格式：按章节顺序，每章用 `## 章节名` 标题，列出 3-5 条核心要点。
- 底部加 `## 回顾问题`，列出 5-10 个自测问题。

## 操作安全

- 修改文件使用 `apply_patch`，遵循最小变更原则。
- 原文件保留备份，不删除；确认新结构完整后再告知我。
- 不擅自改动与 Python 模块无关的内容。
