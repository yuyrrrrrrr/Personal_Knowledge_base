## 1. 编程与 Python 简介

- **编程**：把解决问题的步骤转换为计算机可以执行的指令。
- **程序**：由一系列指令和数据组成，用于完成特定任务。
- **编程语言**：人和计算机沟通的形式化语言，分为低级语言和高级语言。
- **Python**：由 Guido van Rossum 设计的高级编程语言，强调代码可读性和开发效率。

### Python 的特点

- 语法简洁、可读性强，适合初学者。
- 解释型语言，通常不需要单独的编译步骤。
- 动态类型语言，变量在使用时绑定对象。
- 拥有丰富的标准库和第三方生态。
- 跨平台，可在 `Windows`、`macOS`、`Linux` 等系统运行。
- 支持面向对象、函数式和过程式等多种编程范式。

### Python 的应用场景

- 自动化脚本、爬虫、数据处理与数据分析。
- Web 后端、桌面工具和网络服务。
- 人工智能、机器学习、自然语言处理和计算机视觉。

## 2. 开发环境搭建与第一个程序

### 安装 Python 解释器

- 从 Python 官方网站下载对应系统的安装包。
- 安装时建议勾选把 `Python` 加入系统环境变量。
- 在终端执行 `python --version` 或 `python3 --version` 验证安装。

### 配置 IDE

- 常用编辑器包括 `PyCharm`、`Visual Studio Code` 等。
- 选择项目使用的 Python 解释器。
- 开启自动保存、代码格式化和语法检查等基础功能。

### 第一个程序

```python
print("Hello, Python!")
```

- `print()` 把内容输出到终端。
- 字符串必须放在成对的单引号或双引号中。
- 文件通常保存为 `.py` 扩展名，再通过解释器运行。

## 3. 代码规范

- 遵循 `PEP 8`，优先保证代码可读性和一致性。
- 使用 4 个空格缩进，不使用制表符混排。
- 变量和函数使用 `snake_case`，类名使用 `PascalCase`，常量通常使用全大写。
- 运算符两侧、逗号后和注释符号后保留合理空格。
- 每行不宜过长，复杂表达式应拆分。
- 导入语句放在文件顶部，按标准库、第三方库、本地模块分组。
- 名称应见名知意，避免使用难以理解的缩写和单字符名称。

## 4. 注释

- 单行注释以 `#` 开头，用于解释代码的目的、原因或注意事项。
- 注释应简洁并解释“为什么”，避免重复代码表面含义。
- 三引号通常用于多行字符串或文档字符串，不应当作普通注释滥用。
- 函数、类和模块可使用文档字符串记录用途、参数和返回值。
- 开发时可用注释暂时标记代码，但提交前应清理无效注释。

```python
# 根据用户年龄判断是否成年
if age >= 18:
    print("成年")
```

## 5. 变量与标识符

### 变量赋值

```python
user_name = "Alice"
age = 18
```

- `=` 表示赋值，把右侧的值绑定给左侧变量。
- 判断相等使用 `==`，不要与赋值运算符混淆。
- Python 是动态类型语言，同一变量可以重新绑定不同类型的对象。
- `type(value)` 可以查看对象的类型。

### 标识符规则

- 只能由字母、数字和下划线组成，不能以数字开头。
- 不能使用 Python 关键字，例如 `if`、`for`、`class`。
- 区分大小写，`name` 和 `Name` 是两个不同名称。
- 推荐使用有意义、可读性强的英文名称。

### 常用赋值形式

```python
a, b = 1, 2
x = y = 0
first, *rest = [1, 2, 3]
```

- 支持多重赋值、链式赋值和解包赋值。
- 常量通常用全大写命名，例如 `MAX_RETRY = 3`，但 Python 不会强制禁止修改。

## 6. 输入与输出

### 输入

```python
name = input("请输入姓名：")
age = int(input("请输入年龄："))
```

- `input()` 暂停程序并读取用户输入。
- `input()` 的返回值始终是字符串。
- 需要参与数值计算时，必须使用 `int()` 或 `float()` 转换。

### 输出

```python
print("Hello", "Python", sep=", ", end="!\n")
```

- `print()` 可一次输出多个对象。
- `sep` 控制对象之间的分隔符，`end` 控制输出结束符。
- f-string 可以方便地把变量插入字符串。

```python
name = "Alice"
print(f"你好，{name}！")
```
