# Python 基础学习总结

## 1-Python Basic Grammer

- 编程语言用于把解决问题的步骤转换为计算机可执行的指令，Python 具有语法简洁、解释执行、动态类型和生态丰富等特点。
- 开发环境包括 Python 解释器、终端和 IDE，第一个程序通常使用 `print("Hello, Python!")` 验证运行环境。
- 代码规范以 `PEP 8` 为基础，使用 4 个空格缩进、清晰的命名和一致的格式；注释用于解释目的，不能重复代码表面含义。
- 变量通过 `变量名 = 值` 绑定对象，标识符不能以数字开头、不能使用关键字并区分大小写。
- `input()` 获取的输入始终是字符串，参与数值计算前需要转换；`print()` 可控制分隔符和结束符，f-string 常用于输出格式化。

## 2-Data Types And Operators

- Python 常用数字类型包括 `int`、`float` 和 `complex`，浮点数存在精度限制，金额等场景应谨慎处理。
- `bool` 只有 `True` 和 `False`，空容器、`0`、`None` 等通常是假值，非空或非零对象通常是真值。
- 算术运算符包含 `+`、`-`、`*`、`/`、`//`、`%`、`**`，复合赋值运算符可以在赋值的同时完成运算。
- 比较、逻辑、成员、身份和位运算符分别用于值比较、条件组合、容器判断、对象身份判断和二进制位操作。
- 类型转换常用 `int()`、`float()`、`str()` 和 `bool()`；复杂表达式应使用括号或拆分为中间变量，避免依赖优先级记忆。

## 3-String Details

- 字符串可以使用单引号、双引号或三引号创建，支持转义字符和原始字符串；字符串不可变，修改操作通常生成新字符串。
- 字符串支持正向索引、负向索引、切片和遍历，切片结束位置不包含，步长为负数时可反向取值。
- 常用操作包括查询、统计、替换、切分、连接、去空白、大小写转换、字符判断以及编码解码。
- 字符串格式化可以使用 `%`、`str.format()` 和 f-string，f-string 适合直接嵌入变量和格式说明符。
- 正则表达式适合匹配、查找、提取和替换文本模式，常通过 `re.search()`、`findall()`、`sub()`、`split()` 和 `compile()` 使用。

## 4-Data Container

- 列表有序、可变且允许重复；元组有序、允许重复但不可变，单个元组元素后必须保留逗号。
- 列表支持追加、插入、扩展、删除、排序、反转和浅拷贝，元组主要支持查询、拼接、重复和解包。
- 字典使用键值对保存数据，键必须唯一且可哈希；常用操作包括读取、更新、删除、`get()`、`keys()`、`values()` 和 `items()`。
- 集合用于保存不重复元素，支持添加、删除以及并集、交集、差集和对称差集运算；空集合必须使用 `set()`。
- 容器可使用 `for`、`enumerate()`、`zip()` 和解包进行遍历，列表、字典、集合还可以使用推导式完成简单转换和过滤。

## 5-Process Control

- `if`、`elif`、`else` 用于互斥条件分支，代码块通过缩进划分，非布尔对象可以按真值规则参与判断。
- 条件表达式 `满足时的值 if 条件 else 不满足时的值` 适合简单二选一赋值。
- `while` 根据条件重复执行，必须确保循环变量最终能够结束循环，`while True` 需要配合明确的退出条件。
- `for` 用于遍历可迭代对象，`range(start, stop, step)` 生成整数序列，结束值不包含且步长不能为 `0`。
- `break` 结束当前循环，`continue` 跳过本次迭代，`pass` 作为空语句占位；循环的 `else` 仅在未被 `break` 终止时执行。
