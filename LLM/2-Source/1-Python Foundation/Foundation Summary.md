## Day 01 – 入门基础

### 编程语言与自然语言

- **编程语言**：人类与计算机之间交流沟通的语言
    
- **自然语言**：人与人之间交流沟通的语言
    
- **解释器（翻译官）**
    
    - 把代码翻译成二进制让计算机干活
        
    - 把二进制翻译成我们能看得懂的返回回来
        

### 字面量与变量

- **字面量**：程序中被写下来的固定的值
    
- **变量**：`变量名称 = 变量值`
    
    - ⚠️ 注意：`=` 是赋值，在 Python 中等于判断是 `==`
        

### 注释

- **作用**：解释代码，不参与运行，提高可读性
    
- **符号**：`#` 单行注释，`""" """` 多行注释
    
- **快捷键**：`Ctrl + /`
    

### 数据类型

|类型|说明|示例|
|---|---|---|
|`int`|整数|`10`|
|`float`|小数（浮点数）|`3.14`|
|`str`|字符串|`"hello"`|
|`bool`|布尔值（`True` / `False`，首字母大写）|`True`|

### 数据类型转换

- 整数转换：`int()`
    
- 小数转换：`float()`
    
- 字符串转换：`str()`（万能）
    
- ⚠️ 字符串转数字需遵守格式规则
    

### 标识符

- **规则**：不能数字开头，不能是关键字，严格区分大小写
    
- **规范**：见名知意，下划线命名法（如 `user_name`）
    

### 算术运算符

`+` `-` `*` `/` `%` `**` `//`

### 字符串拓展与格式化

- 字符串定义：`''`、`""`、`""""""`
    
- 格式化：`f'{值}'`，返回字符串类型，不仅限于 `print` 中使用
    

### 输入函数 `input()`

- 作用：获取用户键盘输入，**返回类型为字符串**
    
- 若需数值运算，记得类型转换

## Day 02 – 分支与循环

### 分支结构（if / elif / else）

python

if 条件:
    [缩进] 满足条件执行的代码
elif 条件:
    [缩进] 满足条件执行的代码
# elif 可以有多个
else:
    [缩进] 所有条件均不满足执行的代码

- ⚠️ `if`、`elif`、`else` 是单选题，一次只执行一个分支
    

### 判断嵌套

python

if 条件A:
    [缩进] if 条件B:
        [缩进] 先满足条件A再满足条件B执行的代码

### while 循环

python

初始变量
while 条件判断:
    [缩进] 循环体
    [缩进] 条件控制

- **死循环**：`while True:`，跳出用 `break`
    
- **跳出本次循环**：`continue`
    
- ⚠️ `break` 和 `continue` 只控制当前层级循环
    

### for 循环

python

for 临时变量 in 待处理的数据集:
    [缩进] 循环体

### range() 函数

- 格式：`range(起始值, 结束值, 步长)`
    
- ⚠️ 结束值不包含本身

## Day 03 – 容器（字符串、列表、元组）

### 容器概述

- 五大容器：字符串、列表、元组、集合、字典
    
- 最常用：**列表**、**字典**
    

---

### 字符串容器（str）

- **定义**
    
    - 空字符串：`str()`、`''`、`""`、`""""""`
        
    - 非空：`str(值)` 或直接引号内放值
        
- **查询方法**
    
    - `len()` – 长度
        
    - `count(元素)` – 出现次数
        
    - `index(元素)` – 索引位置
        
    - `字符串[索引]` – 根据索引取元素
        
    - `元素 in 字符串` – 判断是否存在
        
- **特殊操作**
    
    - `replace(旧, 新, 次数)` – 替换
        
    - `split(切割符, 次数)` – 切割
        
    - `strip()` – 去除两端空白
        
- **特性**：不可变、有序、支持索引、可放任意数据、可重复
    

---

### 列表容器（list）

- **定义**
    
    - 空列表：`list()` 或 `[]`
        
    - 非空：`list(容器)` 或 `[元素1, 元素2, ...]`
        
- **查询**（同字符串）
    
    - `len()`、`count()`、`index()`、`列表[索引]`、`in`
        
- **新增**
    
    - `append(元素)` – 末尾插入（排队）
        
    - `insert(索引, 元素)` – 指定位置插入（插队），索引过大则放末尾
        
    - `extend(容器)` – 插入整个容器
        
- **删除**
    
    - `del 列表[索引]` – 按索引删除
        
    - `pop(索引)` – 按索引删除，有返回值
        
    - `remove(元素)` – 按值删除
        
    - `clear()` – 清空
        
- **修改**：`列表[索引] = 新值`
    
- **特性**：有序、可重复、可变、支持索引
    

---

### 元组容器（tuple）

- **定义**
    
    - 空元组：`tuple()` 或 `()`
        
    - 非空：`tuple(容器)` 或 `(元素1,)`（**单个元素必须加逗号**）
        
- **查询**（同字符串/列表）
    
- **特性**：有序、可重复、**不可变**、支持索引
    

---

### 容器遍历

- **for 循环**：`for 临时变量 in 容器:`
    
- **while 循环**（需索引）：
    
    python
    
    初始变量 (索引)
    while 条件判断:
        [缩进] 循环体
        [缩进] 条件控制
    

### 容器切片（仅序列容器）

- 格式：`容器[起始:结束:步长]`
    
- 起始省略 → 从头；结束省略 → 到末尾；步长默认 `1`
    

---

## Day 04 – 集合、字典、推导式、三目运算

### 集合容器（set）

- **定义**
    
    - 空集合：`set()`（⚠️ `{}` 是空字典）
        
    - 非空：`set(容器)` 或 `{元素1, 元素2, ...}`
        
- **查询**
    
    - `len()`、`元素 in 集合`
        
- **新增**：`add(元素)`
    
- **删除**
    
    - `pop()` – 随机删除
        
    - `discard(元素)` – 删除指定，不存在不报错
        
    - `clear()` – 清空
        
    - `remove(元素)` – 删除指定，不存在报错
        
- **修改**：`difference_update()`（删）、`update()`（增），本质是先删后增
    
- **特性**：不可重复、无序、不支持索引、**元素必须不可变类型**
    

---

### 字典容器（dict）

- **定义**
    
    - 空字典：`{}` 或 `dict()`
        
    - 非空：`{key: value, ...}`
        
- **查询**
    
    - `len()`
        
    - `字典[key]` 或 `字典.get(key)` – 根据 key 取 value
        
    - `字典.keys()` – 所有 key
        
    - `字典.values()` – 所有 value
        
    - `字典.items()` – 所有键值对
        
    - `元素 in 字典` – 判断 key 是否存在
        
- **新增 / 修改**：`字典[key] = 值`（key 不存在则新增，存在则修改）
    
- **删除**
    
    - `del 字典[key]` – 按 key 删除
        
    - `pop(key, 默认值)` – 删除并返回，若 key 不存在且未设默认值会报错；设默认值则返回该值
        
    - `clear()` – 清空
        
- **特性**：key 不能重复、key 必须不可变类型；字典本身无序（但插入有序），键值对存储
    

---

### 推导式

- **列表推导式**：`变量 = [值 for 临时变量 in 待处理的数据集 if 条件]`
    
- ⚠️ 圆括号的推导式是**生成器**，不是元组推导式
    

### 三目运算

python

变量 = 满足条件执行的代码 if 条件 else 不满足条件执行的代码
# 执行顺序：条件 → 满足 → 不满足

### 字典和集合的遍历

- 只能用 **for 循环**（因为无序无索引）
    

---

## Day 05 – 函数

### 函数定义与调用

- **作用**：封装代码，提高复用性与开发效率
    
- **定义格式**
    
    python
    
    def 函数名(形参1, 形参2, ...):
        [缩进] 函数体
        return 返回值
    
- **调用格式**：`变量 = 函数名(实参1, 实参2, ...)`
    

### 函数类型（按参数与返回值）

|类型|说明|
|---|---|
|无参无返|基本不用|
|无参有返|–|
|有参无返|–|
|有参有返|**最常用**|

- ⚠️ 若没有 `return`，默认返回 `None`
    

### 传参方式

- **位置传参**
    
- **关键字传参**
    
- **不定长传参**
    
    - `*args` – 接收为元组
        
    - `**kwargs` – 接收为字典
        
    - （args 和 kwargs 名称可变，但不推荐改）
        
- **缺省（默认）传参**
    
- ⚠️ 位置传参必须在关键字传参**左侧**
    

### 函数的说明文档

- 在函数体内使用 `""" """`，光标在其中敲回车自动生成
    

### 多返回值

python

def 函数名():
    return x, y, z   # 逗号隔开
# 调用
a, b, c = 函数名()   # 分别接收
# 或用单个变量接收，得到元组

### 函数的嵌套与递归

- **嵌套**：一个函数内调用另一个函数
    
- **递归**：自己调用自己
    

### 匿名函数（lambda）

python

lambda 形参1, 形参2...: 单行表达式 或 函数调用

## Day 06 – 文件操作、OS模块、导入、异常

### 文件操作

#### 打开文件

python

f = open(name, modo, encoding='')

- `name`：文件路径（绝对或相对）
    
- `modo`：权限控制
    
    - `r` – 只读
        
    - `w` – 清空写入
        
    - `a` – 追加写入
        
    - `x` – 独占创建
        
    - `t` – 文本模式（默认）
        
    - `b` – 二进制模式
        
    - `+` – 读写兼有，但保留原特性
        
- `encoding`：字符集（如 `utf8`, `gbk`）
    

#### 写入文件

python

文件对象.write('文本内容')

#### 读取文件

- `read(num)` – 读取指定长度（默认全部）
    
- `readline()` – 读取一行
    
- `readlines()` – 按行读取全部，返回列表
    

#### 关闭文件

python

文件对象.close()

⚠️ 每次打开后必须关闭，否则内存消耗

#### 额外操作

- `文件对象.seek(0)` – 重置光标
    

#### with 语句（自动管理）

python

with 文件操作 as 别名:
    [缩进] 具体文件操作

---

### OS 模块常用操作

- `rename()` – 重命名
    
- `remove()` – 删除
    
- `mkdir()` – 新建目录
    
- `getcwd()` – 获取当前目录
    
- `chdir()` – 切换目录
    

---

### 导入（模块与包）

#### 模块（.py 文件）

- 导入方式（常用度递减）：
    
    1. `import 模块名`（最常用）
        
    2. `import 模块名 as 别名`（名称过长时）
        
    3. `from 模块名 import 函数名`（仅需部分函数）
        
    4. `from 模块名 import 函数名 as 别名`
        
    5. `from 模块名 import *`（不推荐）
        

#### 包（含 `__init__.py` 的文件夹）

- 导入方式：
    
    - `import 包名.模块名`
        
    - `from 包名 import *`（需在 `__init__.py` 中配置 `__all__ = ['模块名']`）
        

---

### 异常处理

python

try:
    可能出现异常的代码
except Exception as e:
    出现异常后处理的代码
else:
    未出现异常执行的代码
finally:
    无论如何都会执行的代码

- `try` 和 `except` 必须同时出现，`else` / `finally` 可选
    
- `else` 在实际开发中很少使用
    
- `Exception` 是所有异常的父类
