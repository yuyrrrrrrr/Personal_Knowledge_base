### 1. 评估指标：考卷评分

_回归问题指标:_

| 指标  | 公式                                                                                  | 特点             |
| --- | ----------------------------------------------------------------------------------- | -------------- |
| MAE | $( \frac{1}{n}\sum_{i=1}^{n} \|y_i - \hat{y_i}\| )$                                 | 预测值与真实值的平均绝对误差 |
| MSE | $( \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y_i})^2 )$                                  | 对大误差惩罚更大       |
| R²  | $( 1 - \frac{\sum_{i=1}^{n}(y_i - \hat{y_i})^2}{\sum_{i=1}^{n}(y_i - \bar{y})^2}$ ) | 表示模型解释力        |

_分类问题指标:_

| 指标   | 计算公式                                                              | 适用场景   |
| ---- | ----------------------------------------------------------------- | ------ |
| 准确率  | $( \frac{TP + TN}{TP + FP + FN + TN} )$                           | 均衡数据   |
| 精确率  | $( \frac{TP}{TP + FP} )$                                          | 注重预测质量 |
| 召回率  | $( \frac{TP}{TP + FN} )$                                          | 注重查全率  |
| F1分数 | $( 2 \times \frac{Precision \times Recall}{Precision + Recall} )$ | 综合指标   |

# 损失函数（Loss Function）详解

## 一、什么是损失函数？

损失函数（也称为代价函数或误差函数）是**用来量化模型预测值与真实值之间差异**的数学函数。它是机器学习中评估模型性能的核心指标。

## 二、损失函数的主要作用

1. **衡量模型性能**：计算预测结果与真实结果的偏差程度
2. **指导模型优化**：为优化算法（如梯度下降）提供调整方向
3. **作为训练目标**：模型训练的目标就是最小化损失函数
4. **比较不同模型**：相同任务下可以用损失值比较不同模型的优劣

## 三、常见损失函数类型及代码示例

### 1. 回归问题常用损失函数

#### (1) 均方误差（MSE）

```python
import numpy as np

def mean_squared_error(y_true, y_pred):
    """
    计算均方误差(MSE)
    
    参数:
    y_true -- 真实值数组
    y_pred -- 预测值数组
    
    返回:
    mse -- 均方误差值
    """
    return np.mean((y_true - y_pred)**2)

# 示例使用
true_values = np.array([3, -0.5, 2, 7])
predicted_values = np.array([2.5, 0.0, 2, 8])
print("MSE:", mean_squared_error(true_values, predicted_values))
```

#### (2) 平均绝对误差（MAE）

```python
def mean_absolute_error(y_true, y_pred):
    """
    计算平均绝对误差(MAE)
    """
    return np.mean(np.abs(y_true - y_pred))

print("MAE:", mean_absolute_error(true_values, predicted_values))
```

### 2. 分类问题常用损失函数

#### (1) 交叉熵损失（Cross-Entropy）

```python
def cross_entropy_loss(y_true, y_pred_prob):
    """
    计算交叉熵损失（适用于概率输出）
    
    参数:
    y_true -- 真实类别标签（0或1）
    y_pred_prob -- 预测为正类的概率
    
    返回:
    loss -- 交叉熵损失值
    """
    epsilon = 1e-15  # 防止log(0)的情况
    y_pred_prob = np.clip(y_pred_prob, epsilon, 1 - epsilon)
    return -np.mean(y_true * np.log(y_pred_prob) + (1 - y_true) * np.log(1 - y_pred_prob))

# 示例使用（二分类问题）
true_labels = np.array([1, 0, 1, 1])
pred_probs = np.array([0.9, 0.1, 0.8, 0.4])  # 模型预测为正类的概率
print("Cross-Entropy Loss:", cross_entropy_loss(true_labels, pred_probs))
```

#### (2) 多分类交叉熵

```python
def categorical_crossentropy(y_true, y_pred_prob):
    """
    多分类交叉熵损失
    
    参数:
    y_true -- 真实类别的one-hot编码
    y_pred_prob -- 每个类别的预测概率
    
    返回:
    loss -- 多分类交叉熵损失值
    """
    epsilon = 1e-15
    y_pred_prob = np.clip(y_pred_prob, epsilon, 1 - epsilon)
    return -np.mean(np.sum(y_true * np.log(y_pred_prob), axis=1))

# 示例使用（三分类问题）
true_labels = np.array([[1, 0, 0], [0, 1, 0], [0, 0, 1]])  # one-hot编码
pred_probs = np.array([[0.7, 0.2, 0.1], 
                      [0.1, 0.8, 0.1], 
                      [0.2, 0.3, 0.5]])
print("Categorical Crossentropy:", categorical_crossentropy(true_labels, pred_probs))
```

## 四、如何选择合适的损失函数

|问题类型|推荐损失函数|特点|
|---|---|---|
|回归问题|MSE, MAE|MSE对异常值敏感，MAE更鲁棒|
|二分类问题|二元交叉熵|适用于概率输出|
|多分类问题|分类交叉熵|需要one-hot编码|
|多标签分类|二元交叉熵|每个标签独立判断|

## 五、损失函数在训练过程中的角色

1. **前向传播**：计算当前参数下的损失值
2. **反向传播**：计算损失函数对各参数的梯度
3. **参数更新**：根据梯度方向调整模型参数

```undefined
输入数据 → 模型预测 → 计算损失 → 反向传播 → 参数更新
```

理解损失函数对于设计和优化机器学习模型至关重要，它直接决定了模型的学习方向和最终性能。

# 梯度下降（Gradient Descent）详解

## 一、什么是梯度下降？

梯度下降是一种**用于优化目标函数的迭代算法**，通过沿着目标函数梯度的反方向逐步调整参数，最终找到函数的极小值点。它是机器学习中训练模型最常用的优化方法之一。

## 二、工作原理

### 1. 核心数学原理

对于参数θ和损失函数J(θ)，梯度下降的更新公式为：

```isbl
θ = θ - η * ∇J(θ)
```

其中：

- η：学习率（步长）
- ∇J(θ)：损失函数在θ处的梯度

### 2. 工作流程

```python
def gradient_descent(X, y, initial_theta, learning_rate, iterations):
    """
    梯度下降算法实现
    
    参数:
    X -- 特征矩阵 (m×n)
    y -- 标签向量 (m×1)
    initial_theta -- 初始参数 (n×1)
    learning_rate -- 学习率
    iterations -- 迭代次数
    
    返回:
    theta -- 优化后的参数
    cost_history -- 每次迭代的损失值记录
    """
    m = len(y)  # 样本数量
    theta = initial_theta
    cost_history = []
    
    for i in range(iterations):
        # 计算预测值和误差
        predictions = X.dot(theta)
        errors = predictions - y
        
        # 计算梯度 (X.T @ errors)/m
        gradient = X.T.dot(errors) / m
        
        # 更新参数
        theta = theta - learning_rate * gradient
        
        # 计算并保存当前损失值
        cost = (errors**2).sum() / (2*m)
        cost_history.append(cost)
        
    return theta, cost_history
```

- **缺点**：大数据集时计算开销大

### 2. 随机梯度下降（Stochastic GD）

- **特点**：每次迭代随机使用一个样本计算梯度
- **优点**：计算速度快，可在线学习
- **缺点**：收敛不稳定，震荡较大

```python
def stochastic_gradient_descent(X, y, initial_theta, learning_rate, epochs):
    """
    随机梯度下降实现
    """
    m = len(y)
    theta = initial_theta
    cost_history = []
    
    for epoch in range(epochs):
        for i in range(m):
            # 随机选择一个样本
            random_index = np.random.randint(m)
            xi = X[random_index:random_index+1]
            yi = y[random_index:random_index+1]
            
            # 计算单个样本的梯度
            prediction = xi.dot(theta)
            error = prediction - yi
            gradient = xi.T.dot(error)
            
            # 更新参数
            theta = theta - learning_rate * gradient
            
        # 每个epoch结束后计算总损失
        total_error = X.dot(theta) - y
        cost = (total_error**2).sum() / (2*m)
        cost_history.append(cost)
        
    return theta, cost_history
```

### 3. 小批量梯度下降（Mini-batch GD）

- **特点**：每次迭代使用一个小批量样本（典型值32-256）
- **优点**：平衡了计算效率和收敛稳定性
- **缺点**：需要调整批量大小

```python
def mini_batch_gradient_descent(X, y, initial_theta, learning_rate, epochs, batch_size):
    """
    小批量梯度下降实现
    """
    m = len(y)
    theta = initial_theta
    cost_history = []
    
    for epoch in range(epochs):
        # 打乱数据
        shuffled_indices = np.random.permutation(m)
        X_shuffled = X[shuffled_indices]
        y_shuffled = y[shuffled_indices]
        
        # 分批处理
        for i in range(0, m, batch_size):
            xi = X_shuffled[i:i+batch_size]
            yi = y_shuffled[i:i+batch_size]
            
            # 计算小批量梯度
            predictions = xi.dot(theta)
            errors = predictions - yi
            gradient = xi.T.dot(errors) / batch_size
            
            # 更新参数
            theta = theta - learning_rate * gradient
            
        # 计算总损失
        total_error = X.dot(theta) - y
        cost = (total_error**2).sum() / (2*m)
        cost_history.append(cost)
        
    return theta, cost_history
```

### 4. 其他高级变体

|变体名称|特点描述|适用场景|
|---|---|---|
|Momentum|引入动量项，加速收敛并减少震荡|高维参数空间、存在局部极小值|
|Nesterov|Momentum的改进版，先看未来位置再调整|更精确的参数更新|
|Adagrad|自适应调整学习率，适合稀疏数据|NLP、推荐系统等稀疏数据场景|
|RMSprop|改进Adagrad的学习率衰减问题|非平稳目标函数|
|Adam|结合Momentum和RMSprop的优点|深度学习等大多数场景|

## 四、梯度下降的关键参数

1. **学习率(η)**：控制每次更新的步长
    
    - 太大：可能震荡甚至发散,无法收敛
    - 太小：收敛速度慢,需要更多迭代
    - 合适的学习率:快速稳定地收敛到最优解
2. **迭代次数**：
    
    - 太少：可能未收敛
    - 太多：计算资源浪费
3. **收敛条件**：
    
    - 损失值变化小于阈值
    - 梯度范数小于阈值

## 五、梯度下降的优缺点

**优点**：

- 概念简单，易于实现
- 适用于大规模数据集（特别是SGD和Mini-batch变体）
- 可以并行化处理

**缺点**：

- 对特征尺度敏感（需做特征缩放）
- 可能陷入局部最优（非凸函数）
- 需要仔细调参（如学习率）

理解梯度下降及其变体的工作原理对于机器学习和深度学习的实践至关重要，它构成了大多数模型训练算法的基础。
