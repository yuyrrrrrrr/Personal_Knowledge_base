## 1. 内容创作

### 文章写作

- 明确主题、目标读者、文章用途和期望字数。
- 提供资料、观点、结构和必须覆盖的要点。
- 指定开头、主体和结尾的组织方式。
- 要求引用来源或区分事实、观点和推测。

### 文案与故事

- 文案提示词应包含产品、受众、卖点、渠道和行动目标。
- 故事提示词应包含背景、人物、冲突、视角和结局方向。
- 风格模仿应限定可参考的特征，不直接复制受版权保护的长文本。
- 生成多个版本后，再根据指标和反馈进行筛选。

```text
角色：品牌文案策划
产品：{product}
受众：{audience}
目标：突出{benefit}，引导用户{action}
要求：输出 3 个标题和 1 段短文案，避免夸大承诺。
```

## 2. 代码生成

- 说明语言、框架、版本、运行环境和输入输出要求。
- 提供现有接口、数据结构、错误信息和最小必要代码。
- 要求代码可运行、包含错误处理，并遵循项目风格。
- 代码解释应关注控制流、数据流、依赖和边界条件。
- 代码审查应关注缺陷、安全、性能、可维护性和测试缺口。
- Bug 修复提示词应包含复现步骤、预期结果、实际结果和环境信息。
- 生成代码后必须执行测试、静态检查和人工审查。

```text
使用 Python 3.12 修复以下函数。
约束：
1. 保持公开函数签名不变。
2. 增加输入边界处理。
3. 说明根因并给出测试用例。
```

## 3. 数据分析

- 数据总结应明确指标、时间范围、维度和分析目标。
- 数据可视化应指定图表类型、坐标、分组和需要表达的结论。
- 洞察发现应区分相关性和因果性，并标记数据局限。
- 对缺失值、异常值、重复值和单位进行说明。
- 要求模型给出计算过程、假设和可验证的数据依据。
- 涉及隐私数据时应脱敏，避免把原始敏感数据发送到不可信服务。

```text
分析以下销售数据：
- 输出 3 条关键趋势。
- 每条必须包含数据依据。
- 标记数据不足或结论不确定的部分。
- 输出 Markdown 表格和简短建议。
```

## 4. 问答系统

- 知识问答应要求基于给定资料回答，资料不足时明确说明。
- 客服对话应设定身份、语气、权限边界和升级人工条件。
- 教育辅导应分步骤解释，并根据用户水平调整深度。
- 对高风险领域应增加免责声明、来源引用和人工确认。
- 对话历史应控制长度，避免旧信息覆盖最新指令。
- 回答应保持上下文一致，并在不确定时提出澄清问题。

## 5. 创意设计

- 图像生成提示词通常包含主体、动作、环境、构图、光线、风格和画幅。
- 创意构思应明确目标、限制、受众和评价标准。
- 头脑风暴可以要求多个方向、反常识角度和不同风险等级。
- 设计类输出应区分事实约束、审美偏好和可选建议。
- 生成多个候选方案后，应按用户目标和实际约束筛选。
- 使用他人作品风格时，应避免直接复制受保护的具体作品。

## 6. 领域提示词设计原则

- 先理解领域术语、流程、法规和风险，再设计提示词。
- 明确知识来源，区分输入资料、模型知识和外部工具结果。
- 输出结构应符合业务流程，字段应能被程序解析。
- 对事实、概率和推断进行标注，减少幻觉误导。
- 建立领域测试集，覆盖正常、边界、对抗和高风险场景。
- 关键领域应引入人工审核、权限控制和操作留痕。
