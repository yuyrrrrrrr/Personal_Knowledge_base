# 张量的基础操作

> [!info] 内容范围
> 本文整理自 `Deep Learning.canvas` 中“张量(Tensor)操作”分支的全部内容。

## 张量是什么

张量是多维数组，在 PyTorch 中以类的形式封装起来。

| 维度 | 名称 | 示例 |
| :--- | :--- | :--- |
| 0 维 | 标量 | 一个单独的数 |
| 1 维 | 向量 | `[1, 2, 3]` |
| 2 维 | 矩阵 | 二维数组 |
| 3 维及以上 | 高阶张量 | 多维数组 |

## 创建张量

### 从数据创建

```python
import torch
import numpy as np

data = [1, 2, 3]

# 最常用，会复制数据
a = torch.tensor(data)

# 尽量共享内存，不复制
b = torch.as_tensor(data)

# NumPy 转张量，共享内存
c = torch.from_numpy(np.array([1, 2, 3]))
```

> [!warning] 内存共享
> `torch.as_tensor` 和 `torch.from_numpy` 可能与原数据共享内存，修改其中一个会影响另一个。

### 按形状填充

```python
torch.zeros(3, 4)       # 全 0
torch.ones(3, 4)        # 全 1
torch.full((3, 4), 7)   # 全部填充指定值
torch.empty(3, 4)       # 未初始化，速度快但值不确定
```

### 序列区间

```python
torch.arange(0, 10, 2)       # 等差数列，右开：[0, 2, 4, 6, 8]
torch.linspace(0, 1, 5)      # 等分，右闭，默认 float
```

### 随机张量

```python
torch.rand(3, 4)             # [0, 1) 均匀分布
torch.randn(3, 4)            # 标准正态分布，初始化权重最常用
torch.randint(0, 10, (3, 4)) # 整数均匀分布，右开
torch.randperm(10)           # 0~9 的随机排列
```

### 特殊矩阵

```python
torch.eye(3)                 # 单位矩阵
torch.diag(torch.tensor([1, 2, 3]))  # 向量构造对角矩阵
```

### 标量与底层创建

```python
torch.scalar_tensor(3.14)    # 0 维标量
```

## 形状变换

```python
x = torch.arange(12)          # shape: [12]

x.reshape(3, 4)               # [3, 4]，能复制就复制，不能就共享
x.view(3, 4)                  # [3, 4]，只能用于连续内存，否则报错
x.reshape(-1)                 # 展平，-1 自动推断
x.flatten()                   # 展平成一维

y = torch.randn(2, 3, 4)
y.transpose(1, 2)             # 交换 dim1 和 dim2 → [2, 4, 3]
y.permute(2, 0, 1)            # 任意重排维度 → [4, 2, 3]

z = torch.randn(1, 3, 1)
z.squeeze()                   # 去掉所有 size=1 的维度 → [3]
z.squeeze(0)                  # 只去掉 dim0
torch.randn(3).unsqueeze(0)   # 插入一个维度 → [1, 3]

e = torch.randn(1, 3)
e.expand(4, 3)                # 广播扩展，不复制内存
```

> [!warning] `view` 的连续内存限制
> `transpose` / `permute` 之后张量通常不连续，再使用 `view` 会报错，需要先调用 `.contiguous()`，或直接使用 `.reshape()`。

```python
y = torch.randn(2, 3)
y.transpose(0, 1).view(-1)              # ❌ 报错
y.transpose(0, 1).contiguous().view(-1) # ✅
y.transpose(0, 1).reshape(-1)           # ✅
```

## 索引与切片

```python
x = torch.arange(12).reshape(3, 4)

x[0]            # 第 0 行
x[:, 1]         # 第 1 列
x[1, 2]         # 第 1 行第 2 列，标量张量
x[0:2, 1:3]     # 切片
x[x > 5]        # 布尔索引，返回一维
x[[0, 2]]       # 花式索引，取第 0、2 行
x[..., 0]       # ... 表示省略前面所有维度
```

> [!warning] 视图与副本
> 切片是视图，修改切片会影响原张量；花式索引和布尔索引返回副本。

```python
y = x[0:1]
y[0, 0] = 999   # 会改到 x
```

## 拼接与拆分

```python
a = torch.randn(2, 3)
b = torch.randn(2, 3)

torch.cat([a, b], dim=0)      # [4, 3]，沿已有维度拼接
torch.cat([a, b], dim=1)      # [2, 6]
torch.stack([a, b], dim=0)    # [2, 2, 3]，新增一个维度

c = torch.randn(6, 3)
torch.split(c, 2, dim=0)      # 按大小 2 切 → 3 个 [2, 3]
torch.chunk(c, 3, dim=0)      # 按份数 3 切 → 3 个 [2, 3]
```

> [!tip] `cat` 与 `stack`
> `cat` 拼接已有维度，`stack` 新增维度。

## 数学运算

```python
a = torch.tensor([1., 2., 3.])
b = torch.tensor([4., 5., 6.])

a + b; a - b; a * b; a / b       # 逐元素运算
a ** 2; torch.pow(a, 2)          # 幂
torch.sqrt(a)                    # 平方根
torch.exp(a)                     # e 的 a 次方
torch.log(a)                     # 自然对数
torch.abs(a)                     # 绝对值
torch.neg(a)                     # 取负

m1 = torch.randn(2, 3)
m2 = torch.randn(3, 4)
m1 @ m2                          # 推荐写法
torch.matmul(m1, m2)
torch.mm(m1, m2)                 # 只能用于二维矩阵

batch1 = torch.randn(10, 2, 3)
batch2 = torch.randn(10, 3, 4)
torch.bmm(batch1, batch2)        # [10, 2, 4]
```

### 广播规则

从右往左对齐，维度相等或其中一个为 1 就可以广播。

```python
torch.randn(3, 4) + torch.randn(4)     # ✅ → [3, 4]
torch.randn(3, 1) + torch.randn(1, 4)  # ✅ → [3, 4]
torch.randn(3, 4) + torch.randn(3)     # ❌ 3 与 4 对不上
```

## 归约与统计

```python
x = torch.randn(3, 4)

x.sum()                     # 全部求和，返回标量
x.sum(dim=0)                # 沿 dim0 求和 → [4]
x.sum(dim=1, keepdim=True)  # → [3, 1]，保留维度方便广播
x.mean(); x.median()        # 注意：整型不能 mean
x.max(); x.min()
x.max(dim=1)                # 返回 (values, indices)
x.argmax(dim=1)             # 只返回索引
x.std(); x.var()
x.cumsum(dim=0)             # 累加
torch.sort(x, dim=1)        # 排序，返回 values 和 indices
```

> [!warning] `x.max(dim=1)` 的返回值
> 返回的是 `torch.return_types.max(values=..., indices=...)`，不是单纯张量。取值用 `.values`，取索引用 `.indices`。

## 比较逻辑

```python
a = torch.tensor([1, 2, 3])
b = torch.tensor([3, 2, 1])

a > b               # tensor([False, False, True])
torch.eq(a, b)      # 相等
torch.all(a > 0)    # 全部为真？
torch.any(a > 2)    # 存在为真？
(a == b).sum()      # 统计相等个数，常用
torch.where(a > 1, a, torch.zeros_like(a))  # 条件选择
```

## 类型与设备转换

```python
x = torch.randn(2, 3)          # float32
x.long()                       # int64
x.int()                        # int32
x.float()                      # float32
x.double()                     # float64
x.to(torch.float16)
x.type(torch.int64)            # 老写法，推荐使用 to
x.cpu()
x.cuda()                       # 有 GPU 才能使用
x.to("cuda:0")
x.to(device="cuda", dtype=torch.float16)
```

> [!warning] 整型张量的限制
> 整型张量不能直接调用 `mean()`，也不能求导；需要先转换成浮点类型，例如 `.float()`。

## 就地操作（in-place）

```python
x = torch.tensor([1., 2., 3.])
x.add_(1)          # 就地加，x 被修改
x.mul_(2)
x.zero_()          # 全部置 0
x.fill_(7)         # 全部填充 7
```

> [!danger] in-place 与自动求导
> in-place 操作会破坏自动求导图。叶子张量（`requires_grad=True`）尽量不要使用 in-place，否则 `backward()` 可能报错：`a leaf Variable that requires grad is being used in an in-place operation`。

## 自动求导相关

```python
x = torch.randn(3, requires_grad=True)
y = (x ** 2).sum()
y.backward()
print(x.grad)          # dy/dx

x.detach()             # 脱离计算图，共享内存
with torch.no_grad():  # 上下文内不记录梯度，推理时使用
    z = x * 2

x.requires_grad_(False)  # 就地关闭梯度记录
```

> [!important] 推理阶段
> 推理和评估阶段要使用 `torch.no_grad()`，否则会额外记录计算图，显存占用会增加。

## NumPy 转换与内存共享

### 张量转 NumPy

```python
x = torch.tensor([1., 2., 3.])
arr = x.numpy()          # CPU 张量可与 NumPy 共享内存
```

### NumPy 转张量

```python
import numpy as np

arr = np.array([1., 2., 3.])
x = torch.from_numpy(arr)  # 共享内存
y = torch.tensor(arr)      # 复制数据
```

> [!warning] 共享内存与复制
> - `x.numpy()` 和 `torch.from_numpy(arr)` 通常共享内存。
> - `torch.tensor(arr)` 会复制数据。
> - 需要断开内存关联时，可以使用 `.clone()` 或 `torch.tensor(...)` 复制；`.copy_()` 是就地复制。
> - GPU 张量或带梯度的张量转 NumPy 时，通常先执行 `x.detach().cpu().numpy()`。

## 综合示例：维度变换、拼接与堆叠

```python
import torch

A = torch.tensor([[1, 2, 3], [4, 5, 6]])
B = torch.tensor([[7, 8, 9], [10, 11, 12]])

A.reshape(3, 2).shape            # (3, 2)
A.unsqueeze(0).shape             # (1, 2, 3)

torch.cat([A, B], dim=0).shape   # (4, 3)
torch.cat([A, B], dim=1).shape   # (2, 6)
torch.stack([A, B], dim=0).shape # (2, 2, 3)
torch.stack([A, B], dim=1).shape # (2, 2, 3)
```

> [!important] 核心区别
> `reshape` / `view` 改变单个张量的形状；`cat` 沿已有维度拼接多个张量；`stack` 新增一个维度后堆叠多个张量。
