## 训练的主循环：四步反复跑

> [!important] 核心公式
> 训练 = 初始化 $\rightarrow$ 重复（前向 $\rightarrow$ 损失 $\rightarrow$ 反向 $\rightarrow$ 更新）$\rightarrow$ 判断停下

### 训练流程图解析

**① 初始化**
- 1.1 网络结构设计（输入层、隐藏层、输出层）
- 1.2 参数初始化（权重 $W \sim \mathcal{N}(0, \sigma^2)$；偏置 $b=0$ 或小随机数）

**② 前向传播**
- 2.1 激活函数（ReLU, Sigmoid, Tanh）
- 2.2 Dropout（训练时随机关闭，推理时所有神经元参与）
- 2.3 归一化（Batch Normalization, Layer Normalization）

**③ 计算损失**
- 3.1 损失函数（回归: MSE $L = \frac{1}{N}\sum(y_i - \hat{y}_i)^2$；分类: 交叉熵 $L = -\sum y_i \log(\hat{y}_i)$）
- 3.2 L1/L2 正则化（L1正则化 $\lambda \sum|W|$；L2正则化 $\lambda \sum W^2$；总损失：$L_{total} = L + \lambda R$）

**④ 反向传播计算梯度**
- 梯度从输出层向前传播，使用链式法则逐层求解 $\frac{\partial L}{\partial W}$ 和 $\frac{\partial L}{\partial b}$。

**⑤ 更新参数**
- 5.1 梯度下降优化器（SGD: $W_{t+1} = W_t - \eta \nabla L$；Adam）
- 5.2 学习率调度（Step Decay, Cosine Annealing）
- 5.3 权重衰减 (L2)（$W_{t+1} = W_t - \eta(\nabla L + \lambda W)$）

**⑥ 重新前向传播，反复训练**
- 6.1 Early Stopping（验证集性能不再提升时停止训练）
- 6.2 过拟合（验证集上性能开始下降时）
- **循环逻辑**：重复迭代（前向传播 $\rightarrow$ 计算损失 $\rightarrow$ 反向传播 $\rightarrow$ 更新参数），直到收敛或满足停止条件。

---

### 各阶段职责速查

| 阶段 | 名称 | 任务 |
| :--- | :--- | :--- |
| **阶段 0** | **初始化** | 定网络结构 + 设参数初值 |
| **① 前向** | **Forward** | 逐层算输出，叠激活 / Dropout / 归一化 |
| **② 损失** | **Loss** | MSE / CE 量化误差，外加 L1/L2 惩罚 |
| **③ 反向** | **Backward** | 链式法则逐层求梯度 $\partial L / \partial W$ |
| **④ 更新** | **Optimize** | 优化器 + 学习率调度 + 权重衰减 |
| **阶段 N** | **停下来** | 看验证集，过拟合就 Early Stopping |

> [!note] 概念区分
> 循环重复成千上万次，每跑一次叫 **iteration**，把整个训练集过一遍叫 **epoch**。

## ① 初始化 · 网络结构设计

训练的起点是确定网络的结构：**多少层、每层多少个神经元、层与层之间如何连接**。一个典型前馈网络由输入层、若干隐藏层、输出层组成，每层都做同一套两步操作：

$$
\text{先做线性变换} \quad z = Wx + b
$$

$$
\text{再加非线性} \quad a = \sigma(z)
$$
![](../../../../image/Pasted%20image%2020261026090344.png)

> [!info] 深度 vs 宽度
> 层数决定**深度**，每层神经元数决定**宽度**。更深更宽 = 更强拟合能力 + 更多参数 + 更高过拟合风险。

> [!tip] 从简到繁
> 先用小模型起步、不够再加深深宽，比一上来就堆叠巨型网络**高效得多**。

## ② 前向传播 · 激活函数

激活函数是神经网络拥有**非线性表达能力**的根本原因。去掉激活，无论多少层都等价于单层线性模型——**100 层和 1 层没有区别**。

### 早期经典：Sigmoid 与 Tanh

| 属性       | Sigmoid                            | Tanh                                             |
| :------- | :--------------------------------- | :----------------------------------------------- |
| **函数**   | $(\sigma(x) = \frac{1}{1+e^{-x}})$ | $(\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}})$ |
| **输出范围** | $(0, 1)$                         | $(-1, 1)$                                      |
| **中心性**  | 非零中心（输出均为正）                        | 零中心                                              |
| **梯度特性** | 两端饱和，梯度趋近于 0                       | 两端饱和，梯度趋近于 0                                     |
| **优点**   | 输出可解释为概率                           | 零中心缓解优化震荡                                        |
| **缺点**   | 梯度消失，优化慢                           | 仍存在梯度消失                                          |
| **适用场景** | 二分类输出层、概率建模                        | 早期隐藏层、RNN 等                                      |

> [!quote] 小结
> Sigmoid 首次让反向传播成为可能，但两端饱和导致梯度消失；Tanh 将输出变为零中心，缓解了优化路径的震荡。

---

### 深度学习时代：ReLU 系列

| 属性 | ReLU | Leaky ReLU | GELU | SiLU (Swish) |
| :--- | :--- | :--- | :--- | :--- |
| **函数** | $f(x) = \max(0, x)$ | $f(x) = \max(\alpha x, x)$<br>$(\alpha = 0.01)$ | $f(x) = x\Phi(x)$<br>$\Phi(x) = \frac{1}{2}[1+\text{erf}(\frac{x}{\sqrt{2}})]$ | $f(x) = x \cdot \sigma(x)$<br>$\sigma(x) = \frac{1}{1+e^{-x}}$ |
| **输出范围** | $[0, +\infty)$ | $(-\infty, +\infty)$ | $(-\infty, +\infty)$ | $(-\infty, +\infty)$ |
| **中心性** | 非零中心 | 零中心（近似） | 零中心（近似） | 零中心（近似） |
| **梯度特性** | 正半轴梯度为 1；<br>负半轴梯度为 0 | 负半轴梯度为 $-\alpha$，<br>缓解 "ReLU 死" | 平滑可导，梯度连续 | 平滑可导，梯度连续 |
| **优点** | 计算极简，训练快；<br>保持正半轴梯度 | 缓解死亡问题；<br>保留负半轴梯度 | 平滑、性能优异<br>(Transformer 主流) | 平滑、性能优异<br>(EfficientNet 等) |
| **缺点** | 存在 "死 ReLU" 现象 | 需设置超参数 $\alpha$ | 计算比 ReLU 略高 | 计算比 ReLU 略高 |
| **适用场景** | CNN、MLP 等经典网络 | 深度网络、稀疏梯度场景 | Transformer、BERT、<br>GPT 等主流模型 | Transformer、EfficientNet、<br>YOLO 等 |

> [!quote] 小结
> ReLU 以极简的形式保住了正半轴的梯度，大幅降低计算成本，直接开启了深度学习时代；GELU 和 SiLU (Swish) 在 ReLU 的基础上把原点附近的硬折角改为平滑过渡，成为 Transformer 时代的标配。

---

### 激活函数一句话点评

> [!info] Sigmoid
> 让反向传播成为可能；两端饱和、梯度消失

> [!success] Tanh
> 零中心化，缓解优化路径震荡

> [!important] ReLU
> 极简、保住正半轴梯度，开启深度学习时代

> [!tip] GELU / SiLU
> 平滑过渡，Transformer 时代标配

---

> [!important] 选型建议
> **输出层 Sigmoid / Softmax，隐藏层 ReLU 仍够用，Transformer / 大模型多用 GELU / SiLU。**

## ② 前向传播 · Dropout

**Dropout** 是一种在前向传播过程中执行的正则化技术。训练时每个神经元都有一定概率（通常 0.1~0.5）被临时关闭，输出强制设为 0。
![](../../../../image/Pasted%20image%2020261025211946.png)

> [!info] 每次都是不同的子网络
> 每次前向传播实际上在一个不同的子网络上进行，**迫使网络不能依赖任何单个神经元**。

> [!success] 学到独立有用的特征
> 每个神经元都必须学到**独立有用的特征**，最终推理相当于成千上万子网络的集体投票。

> [!warning] ⚠️ 别忘了切 `eval()`
> 推理时必须 `model.eval()`，否则继续随机丢弃，准确率暴跌。

## ② 前向传播 · 归一化

参数初始化只能保证**第一次前向传播**时方差稳定。训练推进、权重更新，各层激活值的分布会逐步漂移——归一化的作用就是把这种“方差守恒”**从初始化扩展到整个训练过程**。

---

### Batch Normalization vs Layer Normalization
![](../../../../image/Pasted%20image%2020261026091322.png)

| Batch Normalization (在 batch 维上归一化)                                      | Layer Normalization (在特征维度上归一化)                                                           |
| :----------------------------------------------------------------------- | :---------------------------------------------------------------------------------------- |
| **操作**：不同样本的同一个特征（通道）放在一起，计算均值和方差。                                       | **操作**：同一个样本内，跨所有特征维度（token 表示向量的各维度）计算均值和方差。                                             |
| **矩阵视角**：行是样本（样本1...N），列是特征（特征1...D）。对**每一列**计算$(\mu_j, \sigma_j^2)$。    | **矩阵视角**：行是句子，列是 token。对**每一行**计算 $(\mu_i, \sigma_i^2)$。                                  |
| **适用任务**：**图像任务**。同一特征（如“检测竖线”）在不同图像中激活范围相似，跨样本关联度高，因此在 batch 维上归一化是合理的。 | **适用任务**：**序列任务**。一个 token 的各维度共同编码其语义，同一样本内不同特征之间关联度高，跨样本同一位置的特定特征没有天然联系，因此在特征维度上归一化更合理。 |
| **示例说明**：不管猫还是狗，“检测竖线”这个通道的激活分布相似。                                       | **示例说明**：同一句子内，前后 token 语义相关，表示向量分布有内在联系；不同句子同一位置（如第 3 个词）的表示没有可比性。                       |

---

### 核心方法对比

> [!info] Batch Norm
> 沿 `batch` 维统计，适合 `batch` 较大的 CNN 场景。

> [!success] Layer Norm
> 沿 `feature` 维统计，每个样本独立、不依赖 `batch size`，Transformer 标配。

> [!tip] RMSNorm
> LLaMA / Qwen 简化版，**去掉减均值**只除均方根，效果相当但更快。

## ② 前向传播 · 组装
> [!important] 核心规则
> 每层顺序固定为 `Linear → BN → ReLU → Dropout`，最后一层留下裸 logits 交给损失函数处理。
```python
model = nn.Sequential(
    nn.Flatten(),
    nn.Linear(784, 256), nn.BatchNorm1d(256), nn.ReLU(), nn.Dropout(0.2),
    nn.Linear(256, 256), nn.BatchNorm1d(256), nn.ReLU(), nn.Dropout(0.2),
    nn.Linear(256, 10),   # 最后一层不加激活，输出 logits
)
```
前向传播结束后，模型产生预测值 y^y^​。下一步就是衡量它和真值之间的差距。
## ③ 计算损失 · 损失函数

损失函数把预测 $\hat{y}$ 和真值 $y$ 的差距量化成一个标量 $L$。它本身告诉我们错得有多严重，**它的梯度则是反向传播的起点。**

| 回归 · MSE | 分类 · Cross-Entropy |
| :---: | :---: |
| $$ L = \frac{1}{N} \sum (y_i - \hat{y}_i)^2 $$ | $$ L = - \sum_k y_k \log \hat{y}_k $$ |

分类不能用 MSE：当预测概率接近 0 或 1 时，Sigmoid 梯度趋近 0，**模型反而学不动**。而 $-\log$ 形式让错得越离谱、损失爆炸式增长，梯度也越大。

```python
nn.MSELoss()              # 回归
nn.BCEWithLogitsLoss()    # 二分类（输入 logits，内部自动加 Sigmoid）
nn.CrossEntropyLoss()     # 多分类（输入 logits，内部自动加 Softmax）
```
## ③ 计算损失 · L1 / L2 正则化

单纯最小化训练损失，模型可能学到过于复杂的参数组合，泛化崩溃——这就是过拟合。L1 / L2 在原始损失上引入**权重惩罚项**，迫使模型选择数值更小的权重。
![](../../../../image/Pasted%20image%2020261025211116.png)

| 回归 · L1 正则化 | 分类 · L2 正则化 |
| :---: | :---: |
| $$ \mathcal{L}_{\text{reg}} = \mathcal{L}_{\text{原始}} + \lambda \sum \lvert w_i \rvert $$ | $$ \mathcal{L}_{\text{reg}} = \mathcal{L}_{\text{原始}} + \frac{\lambda}{2} \sum w_i^2 $$ |

> [!info] L1 (Lasso)
> 产生**稀疏权重**，相当于自动特征选择。

> [!success] L2 (Ridge)
> 权重均匀缩小，向 0 靠拢但不为 0。

> [!important] 深度学习偏爱 L2
> 网络很少需要稀疏，而 L2 处处可导，对优化更友好。

## ④ 反向传播 · 计算梯度

反向传播的本质：从损失函数出发，沿前向传播**反方向**，利用链式法则逐层计算损失对每个参数的偏导数。

$$
\frac{\partial L}{\partial W} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial z} \cdot \frac{\partial z}{\partial W}
$$

> [!info] 梯度的方向与大小
> $\partial L / \partial w > 0 \rightarrow$ 减小 $w$；绝对值越大，调整幅度越大。

```python
loss = loss_fn(model(x), y)
loss.backward()  # 自动构建计算图
                 # 一次反向计算所有梯度
```
 
## ⑤ 更新参数 · 优化器演化

$$
W_{t+1} = W_t - \eta \cdot \nabla L
$$

沿梯度反方向走一小步——但实际训练会遇到山谷震荡、参数敏感度差异、初期估计不稳等问题。优化器的演化就是研究者一代代针对这些问题做出的改进。

| 优化器            | 核心特点              | 优化器          | 核心特点           |
| :------------- | :---------------- | :----------- | :------------- |
| **Batch GD**   | 方向准但代价高           | **SGD**      | 单样本估计，速度快但抖动大  |
| **Mini-batch** | 工程上的甜点            | **Momentum** | 引入惯性，缓解震荡      |
| **AdaGrad**    | 每个参数独立学习率         | **RMSProp**  | 滑动平均修复学习率衰减到 0 |
| **Adam**       | 动量 + 自适应步长 + 偏差校正 | **AdamW ★**  | 把权重衰减解耦，现代默认配方 |

```python
# CV 任务常用：传统 CNN 仍偏爱 SGD+Momentum；ViT 已转向 AdamW
optimizer = optim.SGD(model.parameters(), lr=0.1, momentum=0.9)

# NLP / 大模型几乎清一色 AdamW (BERT、GPT、LLaMA、Stable Diffusion)
optimizer = optim.AdamW(model.parameters(), lr=1e-3, weight_decay=1e-2)
```
## ⑤ 更新参数 · 学习率调度

学习率 $\eta$ 是训练中最敏感的**超参数**：太大震荡发散、太小收敛缓慢。**训练不同阶段需要不同步长。**
![](../../../../image/Pasted%20image%2020261026093312.png)

> [!info] Warmup
> 线性预热把学习率从 $0$ 推到目标值，给优化器稳住**动量和二阶矩估计**。

> [!success] Cosine Annealing
> 余弦平滑下降——前期缓降、中期快降、后期再缓降，契合训练各阶段需求。

```python
def lr_lambda(step):
    if step < warmup_steps:
        return (step + 1) / warmup_steps
    progress = (step - warmup_steps) / max(1, total_steps - warmup_steps)
    return 0.5 * (1 + math.cos(math.pi * progress))

scheduler = LambdaLR(optimizer, lr_lambda)  # 每个 batch 调用一次 scheduler.step()
```
## ⑤ 更新参数 · 权重衰减

权重衰减是另一个重要的正则化技术，在每一步参数更新时把权重朝零的方向缩一点：

$$
W_{t+1} = W_t - \eta(\nabla L + \lambda W_t)
$$

| SGD 中 | Adam 中 |
| :--- | :--- |
| 权重衰减与 L2 正则化在数学上**完全等价**。 | L2 项被自适应学习率**扭曲**，正则化效果偏离原意。 |

> [!important] AdamW 的核心改进
> **AdamW** 的核心改进：把权重衰减从梯度通道里分离出来，以**固定比例直接作用于参数**，不再受自适应学习率影响。

```python
optimizer_adamw = torch.optim.AdamW(
    model.parameters(), lr=1e-3, weight_decay=1e-2)
```

## ⑥ 何时停下 · Early Stopping

训练越久不一定越好——模型容量超过任务所需时，会出现典型的过拟合现象：训练 loss 持续下降，但**验证 loss 先降后升**，模型开始记忆噪声而非学习规律。

> [!important] Early Stopping
> **Early Stopping**：持续监控验证集指标，连续若干个 epoch (5~20) 没改善就终止训练，回退到最佳 checkpoint。

```python
best_val_loss = float('inf')
patience, no_improve = 5, 0

for epoch in range(max_epochs):
    train_one_epoch(...)
    val_loss = evaluate(...)

    if val_loss < best_val_loss:
        best_val_loss = val_loss
        no_improve = 0
        torch.save(model.state_dict(), 'best_model.pt')  # 保存当前最佳
    else:
    no_improve += 1
    if no_improve >= patience:
	    break              # 连续五轮没改善, 停止
model.load_state_dict(torch.load('best_model.pt'))  # 回退到最佳
```
