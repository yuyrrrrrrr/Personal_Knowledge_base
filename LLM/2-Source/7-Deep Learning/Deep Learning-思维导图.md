- **深度学习** #核心考点
  - **1. 神经网络基础** #核心考点 #易错点
    - **1.1 感知机** [[2-感知机：深度学习的 Hello World|感知机：深度学习的 Hello World]]
      - **感知机模型**：输入、权重、求和、激活、误差反馈、参数更新构成神经网络雏形。
        - **回顾**：Q：感知机包含哪些核心要素？ A：输入、权重、求和、激活、误差反馈与参数更新。
      - **线性可分与线性不可分**：单层感知机只能划出一条线性决策边界。
        - **回顾**：Q：单层感知机的能力边界是什么？ A：只能处理线性可分问题，不能直接解决 XOR。
      - **感知机的局限性**：无法直接解决 XOR；两层感知机通过隐藏层组合多个线性边界。
        - **回顾**：为什么 XOR 需要隐藏层？单层只能表示线性可分关系，隐藏层先构造多个局部条件，输出层再组合。
    - **1.2 多层感知机 MLP** [[3-深度学习架构：MLP到神经网络的升级，理解反向传播的基础|MLP 与反向传播基础]]
      - **神经元与层**：`z = Wx + b`，`a = f(z)`；同一层神经元并行提取不同特征。
        - **回顾**：Q：一个神经元完成哪两步操作？ A：先做线性变换 z=Wx+b，再通过激活函数得到 a=f(z)。
      - **前向传播**：数据按“线性变换 → 激活 → 下一层”逐层传递；整层计算可写成矩阵乘法，因此适合 GPU。 ![[Pasted image 20261020114238.png]]
        - **回顾**：前向传播的计算顺序是什么？输入 → 逐层仿射与激活 → 输出 logits → 计算损失。
      - **反向传播算法**：从损失出发，沿计算图反向计算梯度；局部梯度逐段相乘，多路径梯度相加。 ![[Pasted image 20261020113430.png]]
        - **易错**：`loss.backward()` 会累加梯度；每次反向传播前应先 `optimizer.zero_grad()` #易错点；**回顾**：Q：为什么每次反向传播前要清零梯度？ A：backward 会累加梯度，不清零会把历史梯度带入本次更新。
      - **链式法则**：复合函数的总导数等于各段局部导数相乘；PyTorch 的 Autograd 自动构建计算图并完成求导。
        - **回顾**：为什么反向传播能训练深层网络？它复用中间结果，从输出端高效地把误差责任逐层分配回去。
    - **1.3 激活函数** [[5-激活函数：为神经网络注入灵魂|激活函数]] #核心考点 #易错点
      - **为什么必须非线性**：没有激活函数，任意多层线性网络仍等价于单层线性模型。
        - **回顾**：Q：去掉激活函数会发生什么？ A：多层线性变换仍可合并为单层线性模型。
      - **Sigmoid / Tanh**：Sigmoid 输出 `(0,1)`，适合二分类输出；Tanh 输出 `(-1,1)`、零中心，但两者两端仍会饱和。
        - **易错**：Sigmoid 饱和区梯度接近 0，深层网络容易出现梯度消失 #易错点；**回顾**：Q：Sigmoid 为什么容易梯度消失？ A：输入过大或过小时进入饱和区，导数接近 0。
      - **ReLU 及其变体**：ReLU 计算简单、保留正半轴梯度；Leaky ReLU 给负半轴留梯度，缓解死亡 ReLU。
        - **回顾**：Q：ReLU 的优点与代价是什么？ A：计算简单且保留正半轴梯度，但可能出现死亡 ReLU。
      - **GELU / SiLU**：平滑非线性，Transformer 与大模型常用 GELU、SiLU。
        - **回顾**：Q：GELU 和 SiLU 常用于哪里？ A：Transformer 与大模型隐藏层，提供平滑非线性。
      - **Softmax**：把多分类 logits 转成总和为 1 的概率分布，不是隐藏层的通用激活。
        - **易错回顾**：Q：为什么使用 CrossEntropyLoss 时不能先手动 Softmax？ A：损失内部已含 LogSoftmax，输入应为裸 logits。#易错点
        - **回顾**：隐藏层、二分类输出层、多分类输出层分别常用什么激活？ReLU/GELU；Sigmoid；Softmax。
    - **1.4 损失函数** [[7-损失函数：告诉模型错了多少|损失函数]] #核心考点 #易错点
      - **MSE**：`L = 1/N Σ(y - ŷ)^2`，适合误差对称、无重尾的回归任务；对离群点敏感。
        - **回顾**：Q：MSE 适合什么任务？ A：误差对称、接近 0 且无重尾的回归任务，但会被离群点放大。
      - **BCE**：二分类交叉熵；推荐 `BCEWithLogitsLoss`，直接接收 logits，数值更稳定。
        - **回顾**：Q：二分类为什么推荐 BCEWithLogitsLoss？ A：它直接从 logits 计算，数值更稳定。
      - **交叉熵 CE**：多分类默认损失，模型输出裸 logits；错误越自信，损失越大、梯度越强。
        - **回顾**：Q：多分类交叉熵的输入是什么？ A：模型最后一层输出的 logits，而不是 Softmax 后的概率。
      - **损失选择**：回归用 MSE，二分类用 BCE，多分类用 Softmax + CE。
        - **易错回顾**：Q：MSE + Sigmoid 的致命问题是什么？ A：预测越自信地错误，Sigmoid 越饱和，梯度反而越小。#易错点
        - **回顾**：优化器和损失函数分别负责什么？优化器决定怎么走，损失函数决定走向哪里。
    - **1.5 优化算法** [[6-梯度下降：神经网络是怎么找到一组好参数的|梯度下降与优化器]] #核心考点
      - **GD / SGD / Mini-batch**：全量 GD 方向准但慢，单样本 SGD 快但噪声大，Mini-batch 在稳定性与 GPU 效率之间折中。
        - **回顾**：Q：GD、SGD、Mini-batch 的核心区别是什么？ A：每次更新使用的样本数不同，分别偏向稳定、快速与工程折中。
      - **Momentum**：累计历史梯度形成惯性，缓解震荡并加速沿稳定方向收敛；`β=0.9` 是常见默认值。
        - **回顾**：Q：Momentum 的核心作用是什么？ A：累积历史梯度形成惯性，缓解震荡并加速稳定方向收敛。
      - **AdaGrad / RMSProp**：AdaGrad 按历史平方梯度逐参数缩放，学习率会持续衰减；RMSProp 用滑动平均修正。
        - **回顾**：Q：AdaGrad 与 RMSProp 的关键区别是什么？ A：AdaGrad 累加全部平方梯度，RMSProp 使用滑动平均。
      - **Adam / AdamW**：Adam 结合一阶矩、二阶矩与偏差校正；AdamW 将权重衰减从自适应梯度中解耦。
        - **易错回顾**：Q：AdamW 为什么比 Adam 更适合大模型？ A：它把权重衰减从自适应梯度中解耦，正则效果更稳定。#易错点
        - **回顾**：CV 与 NLP 的常见优化器选择？CV 常用 SGD + Momentum，NLP/大模型常用 AdamW。
    - **1.6 学习率** [[如何训练一个深度学习模型]] #操作步骤
      - **学习率过大**：损失震荡、发散，参数可能直接跳过好区域。
        - **回顾**：Q：学习率过大会出现什么现象？ A：损失震荡甚至发散，参数可能跳过较优区域。
      - **学习率过小**：收敛慢、长期停在平台区，训练效率低。
        - **回顾**：Q：学习率过小会出现什么现象？ A：收敛缓慢，容易长时间停在平台区。
      - **调度策略**：Warmup 先升后稳，Cosine Annealing 平滑下降，ReduceLROnPlateau 在验证指标停滞时降学习率。
        - **回顾**：训练出现 loss 突然飞升时先检查什么？学习率是否过大、梯度是否爆炸、数据与标签是否异常。
    - **1.7 参数初始化** [[10-参数初始化——你和调参高手就差一点点|参数初始化]] #核心考点 #易错点
      - **不能全零**：同层权重相同会造成对称性，神经元学成重复副本；偏置可以初始化为 0。
        - **回顾**：Q：为什么同层权重不能全部初始化为 0？ A：会造成对称性，多个神经元更新后仍然完全相同。
      - **目标**：同时解决对称性、前向信号尺度和反向梯度稳定。
        - **回顾**：Q：参数初始化要同时解决哪三件事？ A：打破对称性、稳定前向信号尺度、稳定反向梯度。
      - **Xavier**：适合 Sigmoid/Tanh 网络，兼顾输入与输出维度。
        - **回顾**：Q：Xavier 初始化适合什么激活函数？ A：Sigmoid 与 Tanh 等非 ReLU 网络。
      - **He**：适合 ReLU/GELU 网络，标准差常用 `sqrt(2 / fan_in)`。
        - **回顾**：为什么 ReLU 网络常用 He 而不是 Xavier？ReLU 会把负半轴置零，He 用更大的方差补偿信号衰减。
    - **1.8 归一化** [[11-归一化：Transformer 用了都说好的训练技巧|归一化]] #核心考点
      - **BatchNorm**：沿 batch 维统计，适合 batch 较大的 CNN；推理使用训练期累积的 running mean / running var。
        - **回顾**：Q：BatchNorm 的统计维度和推理方式是什么？ A：沿 batch 维统计，推理时使用训练期累积的 running 统计量。
      - **LayerNorm**：对每个样本的特征维归一化，不依赖 batch size，是 Transformer 标配。
        - **回顾**：Q：LayerNorm 为什么适合 Transformer？ A：它在每个样本内部归一化，不依赖 batch size，适合变长序列。
      - **RMSNorm**：去掉减均值，只除以均方根，LLaMA、Mistral、Qwen 等模型常用。
        - **回顾**：Q：RMSNorm 与 LayerNorm 的差别是什么？ A：RMSNorm 去掉减均值，只除以均方根。
      - **Add & Norm**：Transformer 每个子层后执行“残差相加 + LayerNorm”，稳定深层训练。
        - **回顾**：BatchNorm 与 LayerNorm 的关键区别？统计维度不同，前者跨样本，后者在单样本内部。
    - **1.9 正则化与泛化** [[12-过拟合克星——正则化|正则化]] #核心考点 #易错点
      - **过拟合信号**：训练 loss 持续下降、验证 loss 先降后升，训练准确率显著高于验证准确率。
        - **回顾**：Q：如何从训练曲线判断过拟合？ A：训练 loss 持续下降，而验证 loss 先降后升并出现明显差距。
      - **L1 / L2**：L1 倾向稀疏权重，L2 让权重平滑收缩；深度学习更常用 L2/权重衰减。
        - **回顾**：Q：L1 与 L2 正则化的效果有何不同？ A：L1 倾向产生稀疏权重，L2 让权重整体平滑收缩。
      - **Dropout**：训练时随机失活神经元并按 `1/(1-p)` 缩放，推理时全部神经元参与。
        - **回顾**：Q：Dropout 在训练和推理时分别如何工作？ A：训练时随机失活并缩放，推理时全部神经元参与且不再缩放。
      - **Early Stopping / 数据增强**：验证指标连续若干轮不改善就停止；数据增强从数据侧限制过拟合。
        - **易错回顾**：Q：推理前忘记 model.eval() 会怎样？ A：Dropout 继续随机失活，BatchNorm 误用训练统计量，结果不稳定。#易错点
        - **回顾**：权重衰减、Dropout、Early Stopping 分别从哪些角度限制有效容量？
  - **2. PyTorch 深度学习框架** #操作步骤 #核心考点
    - **2.1 PyTorch 基础** [[0-张量的基础操作]]
      - **张量创建**：`torch.tensor` 复制数据；`torch.as_tensor` 与 `torch.from_numpy` 尽量共享内存。
        - **易错**：共享内存时修改一个对象可能影响另一个对象；需要断开时用 `.clone()` 或 `torch.tensor(...)` #易错点；**回顾**：Q：torch.tensor 与 torch.as_tensor 的内存行为有何不同？ A：前者默认复制，后者尽量共享原数据内存。
      - **常用创建**：`zeros/ones/full/empty`、`arange/linspace`、`rand/randn/randint/randperm`、`eye/diag`。
        - **回顾**：`arange` 与 `linspace` 的端点规则？`arange` 右开，`linspace` 默认包含右端点。
      - **形状变换**：`reshape/view/flatten`、`transpose/permute`、`squeeze/unsqueeze/expand`。
        - **易错**：`transpose/permute` 后张量可能不连续，直接 `view` 会报错；改用 `.contiguous().view()` 或 `.reshape()` #易错点；**回顾**：Q：transpose 后为什么有时不能直接 view？ A：张量可能不再连续，需要 contiguous 或改用 reshape。
      - **索引与切片**：基础切片通常返回视图，布尔索引和花式索引返回副本。
        - **回顾**：Q：切片与布尔索引返回视图还是副本？ A：基础切片通常是视图，布尔索引和花式索引返回副本。
      - **拼接与拆分**：`cat` 沿已有维度拼接，`stack` 新增维度后堆叠，`split/chunk` 拆分。
        - **回顾**：`cat` 与 `stack` 的区别？前者不增加维数，后者新增一个维度。
      - **数学与归约**：逐元素运算、矩阵乘法 `@/matmul`、批量矩阵乘 `bmm`、广播、`sum/mean/max/argmax/std`。
        - **易错**：整型张量不能直接 `mean()`，也不能求导；先转浮点类型 #易错点；**回顾**：Q：整型张量为什么不能直接求均值和梯度？ A：均值和自动求导要求浮点类型。
      - **类型与设备**：`.float()/.long()`、`.to(device)`、`.cpu()/.cuda()`；模型与数据必须在同一设备。
        - **回顾**：Q：模型与数据设备不一致会发生什么？ A：运算会报设备不匹配错误。
      - **就地操作**：带下划线的方法（如 `add_`）会修改原张量；叶子张量开启梯度时慎用。
        - **回顾**：`a.add(b)` 与 `a.add_(b)` 的区别？前者返回新张量，后者原地修改 `a`。
    - **2.2 自动求导 Autograd** [[0-张量的基础操作]] #核心考点 #易错点
      - **计算图**：只有 `requires_grad=True` 的张量会记录运算并参与梯度计算。
        - **回顾**：Q：requires_grad=True 的作用是什么？ A：让 Autograd 记录该张量参与的运算并计算梯度。
      - **反向传播**：先 `loss.backward()`，再从 `.grad` 读取梯度；梯度默认累加。
        - **回顾**：Q：反向传播后梯度存放在哪里？ A：存放在各叶子张量的 .grad 属性中，并默认累加。
      - **推理控制**：`torch.no_grad()` 不记录计算图；`detach()` 让张量脱离计算图。
        - **操作**：标准顺序为 `optimizer.zero_grad()` → `loss.backward()` → `optimizer.step()`。
        - **回顾**：为什么推理要使用 `torch.no_grad()`？避免构建无用计算图，降低显存占用并提升速度。
    - **2.3 数据加载 DataLoader** [[如何训练一个深度学习模型]]
      - **Dataset**：定义样本读取与单条数据预处理。
        - **回顾**：Q：Dataset 的职责是什么？ A：定义单条样本的读取、预处理与标签返回。
      - **DataLoader**：负责 batch、shuffle、并行加载；`TensorDataset` 可快速包装张量数据。
        - **回顾**：DataLoader 的两个核心作用？把数据分批，并在训练时提供打乱与并行加载。
    - **2.4 模型定义 nn.Module** [[如何训练一个深度学习模型]]
      - **定义模型**：继承 `nn.Module`，在 `__init__` 中注册层，在 `forward` 中定义计算。
        - **回顾**：Q：自定义 nn.Module 必须实现什么？ A：在 __init__ 注册层，并在 forward 定义前向计算。
      - **参数收集**：`model.parameters()` 自动扫描所有可训练参数。
        - **回顾**：为什么 PyTorch 模型通常不手写参数更新？优化器可统一收集参数并执行更新。
    - **2.5 模型训练流程** [[如何训练一个深度学习模型]] #操作步骤 #核心考点
      - **3 个定义**：定义模型、定义损失函数、定义优化器。
        - **回顾**：Q：训练前必须定义哪三样对象？ A：模型、损失函数、优化器。
      - **2 个遍历**：外层遍历 epoch，内层遍历 batch。
        - **回顾**：Q：训练的两层循环分别遍历什么？ A：外层遍历 epoch，内层遍历 batch。
      - **5 个步骤**：前向传播 → 计算损失 → 梯度清零 → 反向传播 → 参数更新。
        - **操作**：`y_pred = model(x)`；`loss = criterion(y_pred, y)`；`optimizer.zero_grad()`；`loss.backward()`；`optimizer.step()`。
        - **回顾**：为什么必须在 `backward()` 前清零梯度？不清零会与上一轮梯度累加，导致更新方向错误。
    - **2.6 评估、保存与加载**
      - **评估**：`model.eval()` + `torch.no_grad()`，记录验证集损失与指标。
        - **回顾**：Q：评估阶段的标准写法是什么？ A：model.eval() 配合 torch.no_grad()，记录验证指标。
      - **保存**：优先保存 `model.state_dict()`；加载时先重建结构，再 `load_state_dict()`。
        - **回顾**：为什么推荐保存 `state_dict` 而不是整个模型对象？结构与参数解耦，迁移和加载更稳定。
    - **2.7 常用组件与 GPU 加速**
      - **常用层**：`nn.Linear`、`nn.Conv2d`、`nn.RNN`、`nn.Dropout`、`nn.BatchNorm`。
        - **回顾**：Q：PyTorch 常用网络层有哪些？ A：Linear、Conv2d、RNN、Dropout、BatchNorm 等。
      - **优化器**：`torch.optim.SGD`、`torch.optim.Adam`、`torch.optim.AdamW`。
        - **回顾**：Q：PyTorch 常用优化器有哪些？ A：SGD、Adam、AdamW 等。
      - **设备迁移**：`.to(device)` 同时迁移模型和张量；多 GPU 可使用 `DataParallel/DistributedDataParallel`。
        - **易错回顾**：Q：GPU 训练时设备不一致错误如何产生？ A：模型或输入张量只迁移了一方。#易错点
        - **回顾**：`.cuda()` 与 `.to(device)` 如何选择？优先使用 `.to(device)`，便于在 CPU/GPU 间切换。

      - **图像表示**：彩色图像通常是 `C × H × W` 张量，例如 `3 × 32 × 32`。
        - **回顾**：Q：PyTorch 中彩色图像的形状是什么？ A：通常是 3×H×W，即通道在前。
      - **MLP 的问题**：展平破坏空间结构，参数随图像尺寸快速膨胀，且无法利用局部相关与平移等变。
        - **回顾**：Q：MLP 直接处理图像有哪三类问题？ A：破坏空间结构、参数膨胀、无法利用局部相关与平移等变。
      - **图像三性质**：局部相关性、平移等变性、层次结构；对应 CNN 的局部连接、参数共享和逐层抽象。 ![[Pasted image 20261026103536.png]]
        - **回顾**：CNN 为什么比 MLP 更适合图像？保留空间结构，用局部连接和共享卷积核大幅减少参数。
      - **卷积层**：卷积核在局部窗口逐项相乘求和，输出特征图；卷积核权重由训练学习。 ![[Pasted image 20261026104018.png]]
        - **回顾**：特征图中的响应值代表什么？当前位置局部区域与卷积核模式的匹配程度。
      - **卷积参数**：`K` 为卷积核大小，`S` 为步长，`P` 为填充。
        - **回顾**：Q：卷积输出尺寸如何计算？ A：H_out=floor((H_in+2P-K)/S)+1，宽度同理。
        - **回顾**：`3×3` 卷积配 `padding=1, stride=1` 时输出空间尺寸如何变化？保持不变。
      - **通道与参数共享**：一个卷积核覆盖全部输入通道但只生成一张特征图；输出通道数等于卷积核数量。
        - **回顾**：卷积层参数量如何计算？`C_out × (C_in × K × K) + C_out`。
      - **池化层**：最大池化保留局部最强响应，降低分辨率、扩大后续感受野。
        - **回顾**：Q：池化层的核心作用是什么？ A：降低分辨率、扩大有效视野并减少计算量。
      - **Flatten + Linear**：卷积提取高层特征后，展平并映射到类别得分；分类推理时可用 Softmax。
        - **回顾**：CNN 最后仍用全连接为什么没问题？此时输入已是尺寸更小、语义更强的高层特征。
    - **3.2 经典 CNN 模型** [[2-CNN 3 池化、分类与代码示例|池化、分类与代码示例]]
      - **LeNet**：早期手写数字识别 CNN，确立卷积、池化、全连接的基本范式。
        - **回顾**：Q：LeNet 的历史地位是什么？ A：奠定卷积、池化、全连接的基本 CNN 范式。
      - **AlexNet**：加深网络并使用 ReLU、Dropout、GPU 训练，推动深度学习爆发。
        - **回顾**：Q：AlexNet 的关键突破是什么？ A：ReLU、Dropout、GPU 训练与更深的网络结构。
      - **VGG**：重复堆叠小卷积核，体现“小核多层”扩大感受野的设计。
        - **回顾**：Q：VGG 的核心设计思想是什么？ A：重复堆叠小卷积核，用深度换更大感受野。
      - **Inception / GoogLeNet**：多分支并行卷积与池化，提取多尺度特征。
        - **回顾**：Q：Inception 模块解决什么问题？ A：用多分支并行卷积提取多尺度特征。
      - **ResNet**：残差连接解决深层网络退化问题，是 CNN 和 Transformer 的共同基础组件。
        - **回顾**：VGG 为什么偏好 `3×3` 卷积？参数少、非线性更多，多层堆叠可获得大感受野。
    - **3.3 残差连接 ResNet** [[3-残差连接： CNN 和 Transformer 的共同捷径|残差连接]] #核心考点 #易错点
      - **退化问题**：深层网络训练误差反而更高，原因是优化困难，不是过拟合。
        - **回顾**：Q：深层网络的退化与过拟合有何不同？ A：退化是训练误差也变差，属于优化问题；过拟合是训练好但验证差。
      - **残差思想**：主路径学习修正量 `F(x)`，跳跃连接保留原信息，输出为 `F(x) + x`。
        - **回顾**：Q：残差连接的前向公式是什么？ A：输出为 F(x)+x，主路径只学习修正量 F(x)。
      - **形状对齐**：同 stage 内直接恒等相加；进入新 stage 时用 `stride=2` 下采样，并可用 `1×1` 卷积投影 shortcut。
        - **回顾**：Q：什么时候需要给 shortcut 做投影？ A：通道数或空间尺寸不匹配时。
      - **BasicBlock / Bottleneck**：BasicBlock 堆叠两个 `3×3` 卷积；Bottleneck 用 `1×1 → 3×3 → 1×1` 压缩中间通道。
        - **回顾**：Q：Bottleneck 为什么能省计算？ A：先用 1×1 降通道，再 3×3 卷积，最后 1×1 升回。
      - **GAP**：全局平均池化把每个通道压成一个数，替代大尺寸全连接层并减少参数。
        - **易错回顾**：Q：残差连接主要解决过拟合还是退化？ A：解决深层网络退化与优化困难，不是过拟合。#易错点
        - **回顾**：为什么让 `F(x)` 学成 0 比直接学恒等映射更容易？输出自动等于输入，网络只需学习微小增量。
    - **3.4 迁移学习** [[2-CNN 3 池化、分类与代码示例|池化、分类与代码示例]]
      - **预训练模型**：先在大规模数据上学习通用特征。
        - **回顾**：Q：预训练模型的价值是什么？ A：在大规模数据上学习通用特征，降低目标任务的数据与训练成本。
      - **微调**：替换任务头，冻结或小学习率更新主干，再用目标任务数据训练。
        - **回顾**：小数据集为什么优先迁移学习？减少从零训练的数据需求与时间成本，同时保留通用特征。
    - **3.5 图像任务** [[0-CNN 第一课：CV 任务为什么需要 CNN|CNN 第一课]]
      - **图像分类**：输出整张图的类别。
        - **回顾**：Q：图像分类的输出是什么？ A：整张图像对应的类别或类别概率。
      - **目标检测**：输出类别、边界框与置信度，常用 IoU、NMS、mAP 评估。
        - **回顾**：Q：目标检测通常输出什么、如何评估？ A：输出类别、框和置信度，常用 IoU、NMS、mAP。
      - **图像分割**：为像素或区域分配类别，输出更细粒度的空间掩码。
        - **回顾**：分类、检测、分割的输出粒度有什么不同？整图类别、实例/框、像素级区域。
  - **4. 循环神经网络 RNN** #核心考点 #易错点
    - **4.1 Embedding 与 Word2Vec** [[0-Embedding 与word2vec：模型如何理解一个词|Embedding 与 Word2Vec]]
      - **One-Hot 的问题**：维度高、稀疏，且所有词彼此正交，无法表达语义相似性。
        - **回顾**：Q：One-Hot 的三个主要缺点是什么？ A：维度高、稀疏、所有词正交且无相似性。
      - **分布假说**：一个词的意义可由它经常出现的上下文体现。
        - **回顾**：Q：分布假说的核心观点是什么？ A：词义可以由它经常出现的上下文推断。
      - **Embedding**：把离散词映射为低维、稠密、可学习的连续向量。
        - **回顾**：Q：Embedding 相比 One-Hot 的优势是什么？ A：低维、稠密、可学习，并能表达语义相似性。
      - **CBOW / Skip-Gram**：CBOW 用上下文预测中心词；Skip-Gram 用中心词预测周围词。
        - **回顾**：CBOW 与 Skip-Gram 的方向和偏好？CBOW 更快、偏高频；Skip-Gram 对低频词通常更友好。
    - **4.2 RNN 基础** [[1-RNN：模型开始理解自然语言序列|RNN 基础]] #核心考点
      - **为什么需要 RNN**：前馈网络无法自然建模词序、变长序列和前后依赖。
        - **回顾**：Q：为什么前馈网络不适合直接处理文本序列？ A：缺少词序建模机制，且难以自然处理变长输入。
      - **隐藏状态**：`h_t = f(W_xh x_t + W_hh h_{t-1} + b_h)`，前文信息被压缩进固定维度向量。 ![[Pasted image 20261027102330.png]]
        - **回顾**：隐藏状态在 RNN 中承担什么角色？压缩历史上下文，并传递给下一时间步和任务头。
      - **时间步展开与参数共享**：同一个 Cell 沿序列重复调用，参数量与序列长度解耦。
        - **回顾**：Q：RNN 参数共享带来什么好处？ A：参数量与序列长度解耦，同一套规则可处理任意长度序列。
      - **三类输出方式**：整体分类只在最后输出；序列标注每个位置输出；序列生成每个位置预测下一个 token。
        - **回顾**：Q：RNN 的三类输出方式是什么？ A：整体分类、序列标注、序列生成。
      - **RNN 的局限**：长距离信息衰减、固定状态信息瓶颈、时间步串行导致难以并行。
        - **易错回顾**：Q：RNN 共享参数时梯度如何处理？ A：各时间步梯度累加到同一组共享参数上。#易错点
        - **回顾**：RNN 为什么难以并行？`h_t` 必须等待 `h_{t-1}` 计算完成。
    - **4.3 LSTM 与 GRU** [[2-LSTM 与 GRU 改进 RNN 带来长期记忆|LSTM 与 GRU]] #核心考点 #易错点
      - **LSTM 状态**：隐藏状态 `h_t` 与细胞状态 `c_t` 分离，长期记忆走加法路径。 ![[Pasted image 20261027151122.png]]
        - **遗忘门**：控制旧细胞状态保留多少。**回顾**：Q：遗忘门控制什么？ A：上一时刻细胞状态有多少继续保留。
        - **输入门**：控制候选新记忆写入多少。**回顾**：Q：输入门控制什么？ A：候选新记忆有多少写入当前细胞状态。
        - **输出门**：控制当前细胞状态有多少暴露为隐藏状态。**回顾**：Q：输出门控制什么？ A：当前细胞状态有多少暴露为隐藏状态。
      - **LSTM 更新**：`c_t = f_t × c_{t-1} + i_t × c̃_t`；`h_t = o_t × tanh(c_t)`。
        - **回顾**：Q：LSTM 的状态更新公式是什么？ A：c_t=f_t×c_{t-1}+i_t×c̃_t，h_t=o_t×tanh(c_t)。
      - **GRU**：合并为重置门与更新门，不单独维护细胞状态；`h_t = z_t × h_{t-1} + (1-z_t) × h̃_t`。
        - **回顾**：Q：GRU 用哪两个门替代 LSTM 的三门？ A：重置门与更新门。
      - **结构选择**：参数量 RNN < GRU < LSTM；GRU 更轻，LSTM 表达与门控更完整。
        - **易错回顾**：Q：LSTM/GRU 为什么仍不能完全并行？ A：状态更新仍依赖前一时刻，时间步必须串行。#易错点
        - **回顾**：LSTM 为什么比普通 RNN 更容易保留长期信息？细胞状态通过加法路径传递，梯度不必反复经过复杂非线性重写。
    - **4.4 Seq2Seq** [[3-编码器-解码器 与 seq2seq|编码器-解码器与 Seq2Seq]] #核心考点 #操作步骤
      - **Encoder-Decoder**：Encoder 读入源序列并压缩为上下文，Decoder 以该上下文为条件生成目标序列。
        - **回顾**：Q：Encoder-Decoder 的职责如何分工？ A：Encoder 编码源序列，Decoder 依据上下文生成目标序列。
      - **训练**：使用 Teacher Forcing，把真实目标序列右移一位作为 Decoder 输入，原目标作为监督标签。
        - **回顾**：Q：Teacher Forcing 的做法是什么？ A：每个解码位置都使用真实的前一目标 Token 作为输入。
      - **推理**：自回归生成，从 `<BOS>` 开始，把上一步输出接回下一步，直到 `<EOS>` 或长度上限。
        - **操作**：输入 `<BOS> 我 喜欢`；目标 `我 喜欢 深度`；按位置计算交叉熵并忽略 `<PAD>`。
        - **易错回顾**：Q：Teacher Forcing 改变了什么？ A：改变 Decoder 的每步输入，不改变交叉熵损失。#易错点
        - **回顾**：Seq2Seq 的两个经典局限？串行计算慢，固定上下文向量形成信息瓶颈。
    - **4.5 注意力机制 Attention** [[4-注意力机制：大模型前夜的最后一块拼图|注意力机制]] #核心考点 #操作步骤
      - **核心目的**：Decoder 在每个生成时刻动态关注 Encoder 的不同位置，而不是只依赖固定上下文。
        - **回顾**：Q：Attention 解决 Seq2Seq 的什么问题？ A：固定上下文向量的信息瓶颈，让解码器动态读取不同输入位置。
      - **四步计算**：相关打分 → Softmax 归一化 → 对 Value 加权求和 → 与 Decoder 当前状态结合预测。 ![[Pasted image 20261101093518.png]]
        - **操作**：`score = QK^T` → `α = softmax(score)` → `context = αV` → 拼接当前状态预测输出。
      - **Q / K / V**：Query 表示当前需要什么，Key 用于匹配，Value 是实际被汇总的信息。
        - **回顾**：Q：Q、K、V 分别表示什么？ A：当前查询需求、匹配键、被汇总的信息值。
      - **Self-Attention**：Q、K、V 都来自同一序列，每个位置可直接读取其他位置。
        - **回顾**：Attention 为什么能缓解信息瓶颈？它允许模型按当前需要动态读取全部输入位置，而非压缩进单一向量。
  - **5. Transformer** #核心考点 #易错点
    - **5.1 前置概念** [[0-Transformer 前置概念回顾|Transformer 前置概念]]
      - **核心数学**：标量、向量、矩阵、张量；点积产生匹配分数，矩阵乘法批量计算。
        - **回顾**：Q：Attention 的核心矩阵计算是什么？ A：QK^T 得到匹配分数，再经 Softmax 与 V 相乘。
      - **基础组件**：Embedding、Encoder-Decoder、Seq2Seq、Attention、Softmax、线性变换、激活、FFN、残差、归一化。
        - **回顾**：Softmax 在 Attention 和分类输出中分别代表什么？位置权重与类别概率。
    - **5.2 Transformer 架构** [[1-Transformer|Transformer]] [[2-手搓 Mini Transformer前需要了解的编码器和解码器|手搓 Mini Transformer]]
      - **整体结构**：Encoder 与 Decoder 均堆叠 `Nx` 层；每个子层后接 Add & Norm。 ![[Pasted image 20261101143107.png]]
        - **回顾**：Q：Transformer 如何把位置信息注入 Token 表示？ A：将 PositionalEncoding(i) 直接加到对应 Token 的 Embedding 上。
      - **Self-Attention**：`Attention(Q,K,V) = softmax(QK^T / sqrt(d_k))V`。
        - **回顾**：Q：Attention 为什么要除以 sqrt(d_k)？ A：控制点积方差，避免 Softmax 过度尖锐和梯度过小。
        - **回顾**：Attention 公式中 Softmax 的作用？把匹配分数转换为总和为 1 的位置权重。
      - **Multi-Head Attention**：多套独立的 Q/K/V 投影并行关注不同子空间，拼接后经 `W_O` 融合。
        - **回顾**：Q：多头注意力如何控制计算量？ A：把 d_model 拆成 h 个头，每个头处理 d_model/h 维。
        - **回顾**：多头注意力为什么还要输出线性映射 `W_O`？让不同头的信息在输出维度上真正混合。
      - **Add & Norm / FFN**：残差保留原信息并提供短梯度路径；LayerNorm 稳定每个 Token 的表示尺度；FFN 先升维再降维。
        - **回顾**：Transformer 为什么用 LayerNorm 而不是 BatchNorm？序列长度可变，且每个样本内部特征相关性更自然。
      - **Masked Self-Attention**：因果掩码把未来位置的匹配分数设为负无穷，Softmax 后权重为 0。
        - **易错回顾**：Q：因果掩码主要解决训练还是推理的问题？ A：主要防止训练时看到未来答案，使训练与自回归推理一致。#易错点
        - **回顾**：因果掩码如何保证训练与推理一致？每个位置只能访问自己和之前的前缀。
      - **Cross-Attention**：Query 来自 Decoder，Key 和 Value 来自 Encoder，用于读取源序列信息。
        - **回顾**：三类注意力的区别是什么？只在于 Q、K、V 分别来自哪个序列。
      - **训练与推理**：训练可用 Teacher Forcing 一次并行计算全部位置；推理必须自回归逐步生成。
        - **KV Cache**：缓存历史 Token 的 Key/Value，避免每步重算；Query 只服务当前位置，通常不缓存。**回顾**：Q：为什么缓存 K、V 而不缓存 Q？ A：历史 K/V 会被后续位置复用，Q 通常只服务当前一次查询。
        - **回顾**：Q：Temperature、Top-K、Top-P 分别做什么？ A：调分布平滑度、固定候选数、按累计概率动态截断。
        - **回顾**：为什么训练可并行而推理通常不能？训练时完整目标序列已知，推理时下一个 Token 尚未产生。
    - **5.3 BERT** [[NLP概述]] #核心考点
      - **架构**：Encoder-only Transformer，擅长理解类任务与句子级表示。
        - **回顾**：Q：BERT 属于哪类 Transformer？ A：Encoder-only，偏双向理解与表示学习。
      - **Masked Language Model**：随机遮盖部分 Token，根据左右上下文预测被遮词。
        - **回顾**：Q：Masked Language Model 如何训练？ A：随机遮盖 Token，利用左右上下文预测被遮词。
      - **Next Sentence Prediction**：判断两个句子是否为连续上下文关系。
        - **回顾**：Q：Next Sentence Prediction 判断什么？ A：判断两个句子是否连续相邻。
      - **预训练 + 微调**：先学习通用语言表示，再适配分类、问答等下游任务。
        - **回顾**：BERT 与 GPT 的核心方向差异？BERT 偏双向理解，GPT 偏自回归生成。
    - **5.4 GPT** [[NLP概述]] #核心考点
      - **架构**：Decoder-only Transformer。
        - **回顾**：Q：GPT 属于哪类 Transformer？ A：Decoder-only，使用因果自注意力。
      - **训练目标**：给定前文预测下一个 Token，本质是自回归语言建模。
        - **回顾**：Q：GPT 的训练目标是什么？ A：给定前文预测下一个 Token。
      - **能力来源**：规模扩大后，语法、词义、事实、风格与推理模式被压进同一个训练目标。
        - **回顾**：为什么“预测下一个 Token”能学到多种任务？大量文本中的任务模式会被统一转化为条件生成问题。
    - **5.5 LLM** [[NLP概述]]
      - **训练范式**：大规模预训练 → 指令微调 / 对齐 → 部署推理。
        - **回顾**：Q：LLM 的典型训练链路是什么？ A：大规模预训练，再指令微调/对齐，最后部署推理。
      - **规模规律**：模型参数、数据量与计算量共同影响能力，规模扩大可带来更强的通用性与上下文学习。
        - **回顾**：Q：影响大模型能力的三个规模因素是什么？ A：参数量、数据量与计算量。
      - **训练技巧**：混合精度、梯度累积、梯度检查点、数据/模型/流水线并行、Flash Attention。
        - **回顾**：Q：大模型训练常见工程技巧有哪些？ A：混合精度、梯度累积/检查点、并行训练、Flash Attention。
      - **压缩与部署**：量化、剪枝、蒸馏；推理侧使用批处理、KV Cache、连续批处理等优化。
        - **回顾**：Q：LLM 压缩与部署有哪些常见手段？ A：量化、剪枝、蒸馏，以及批处理与 KV Cache。
      - **Transformer 变体**：RoPE、GQA、MoE、RMSNorm 等围绕位置、注意力效率与参数利用持续演进。
        - **回顾**：LLM 的“预训练 + 微调”分别学什么？预训练学通用语言规律，微调学任务指令与对齐偏好。
  - **6. 项目实战** #操作步骤
    - **6.1 图像分类项目** [[8-MNIST：深度学习界的 Hello World|MNIST 实战]] #操作步骤
      - **数据**：MNIST/CIFAR；归一化、数据增强、训练/验证/测试划分。
        - **回顾**：Q：图像分类的数据准备包含哪些步骤？ A：归一化、数据增强与训练/验证/测试划分。
      - **模型**：MLP 或 CNN；输出类别 logits。
        - **回顾**：Q：分类模型最后应输出什么？ A：类别 logits，损失函数内部再处理概率。
      - **训练**：CrossEntropyLoss + SGD/AdamW；按 epoch/batch 执行标准五步。
        - **回顾**：Q：分类训练的核心组件是什么？ A：交叉熵损失、优化器与标准五步训练循环。
      - **评估**：准确率、混淆矩阵、分类报告。
        - **操作**：输入 `28×28` 图像 → 展平 `784` 或经 CNN → logits → CrossEntropy → 反向传播 → 更新参数。
        - **回顾**：分类项目为什么不能对 logits 再手动 Softmax 后送入 `CrossEntropyLoss`？损失函数内部已包含 LogSoftmax。
    - **6.2 目标检测项目**
      - **输出**：类别、边界框坐标、置信度。
        - **回顾**：Q：检测模型的输出包含什么？ A：类别、边界框与置信度。
      - **关键步骤**：候选框 → 分类与回归 → 置信度过滤 → NMS 去重。
        - **回顾**：Q：检测后处理为什么需要 NMS？ A：去除同一目标周围高度重叠的冗余框。
      - **评估**：IoU 衡量框重叠，mAP 汇总不同类别与阈值下的检测性能。
        - **回顾**：NMS 解决什么问题？去除同一目标周围高度重叠的冗余检测框。
    - **6.3 NLP 项目** [[NLP概述]] #操作步骤
      - **文本分类**：Tokenization → Embedding → RNN/Transformer → 分类头 → 交叉熵。
        - **回顾**：Q：文本分类的完整前向链路是什么？ A：Tokenize→Embedding→上下文编码→分类头→交叉熵。
      - **机器翻译 / 生成**：Encoder-Decoder 或 Decoder-only → 自回归生成 → BLEU/困惑度评估。
        - **回顾**：Q：生成式 NLP 任务的推理链路是什么？ A：编码输入，自回归生成 Token，直到 EOS 或长度上限。
      - **数据处理**：统一词表，处理 `<PAD>`、`<BOS>`、`<EOS>`；损失中忽略 PAD。
        - **操作**：文本 → Token ID → Embedding → 上下文表示 → 输出分布 → 解码策略 → 文本。
        - **回顾**：生成任务训练与推理的输入差异？训练用真实前缀（Teacher Forcing），推理用模型自己的历史输出。
    - **6.4 通用训练与评估闭环** [[如何训练一个深度学习模型]]
      - **划分数据**：训练集用于学习，验证集用于调参与早停，测试集用于最终评估。
        - **回顾**：Q：训练集、验证集、测试集分别做什么？ A：学习参数、调参与早停、最终独立评估。
      - **选择指标**：分类看 Accuracy/Precision/Recall/F1/混淆矩阵；回归看 MSE/RMSE/MAE/R²。
        - **回顾**：Q：分类与回归的常用指标分别是什么？ A：分类看 Accuracy/F1/混淆矩阵，回归看 MSE/MAE/R²。
      - **排查顺序**：数据与标签 → 模型前向 → 损失与 logits → 梯度 → 优化器与学习率 → 过拟合。
        - **回顾**：验证集 loss 先降后升说明什么？模型开始过拟合，应早停、正则化或增加数据。
  - **7. 深度学习与机器学习的区别** #核心考点
    - **模型结构**：传统机器学习模型通常较浅；深度学习使用多层神经网络逐层学习表示。
      - **回顾**：Q：深度学习与传统机器学习的模型深度差异是什么？ A：深度学习使用多层表示学习，传统模型通常更浅。
    - **特征提取**：传统方法依赖人工设计特征；深度学习可从原始数据中自动学习特征。
      - **回顾**：Q：特征工程上的核心差异是什么？ A：传统方法依赖人工特征，深度学习自动学习分层特征。
    - **数据与计算**：深度学习通常需要更多数据和算力，尤其依赖 GPU；传统方法在小数据场景更轻量。
      - **回顾**：Q：深度学习的主要资源代价是什么？ A：通常需要更多数据、算力与 GPU 资源。
    - **性能与解释性**：大数据任务中深度学习常取得更强性能，但模型通常是黑箱，解释难度更高。
      - **回顾**：深度学习相对传统机器学习的核心优势与代价？优势是自动特征学习和复杂模式拟合，代价是数据、算力与可解释性要求更高。
