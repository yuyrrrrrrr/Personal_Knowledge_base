## 机器学习 vs 深度学习

深度学习让模型**自己学出特征**，并用它们完成预测。

深度学习属于机器学习，两者都追求对新数据的泛化能力。传统机器学习通常先由人设计特征，再训练模型；深度学习把特征提取与预测一并训练。
![](Pasted%20image%2020261108172319.png)
## 感知机与多层神经网络

多层神经网络用**隐藏层与非线性**处理线性边界无法分开的数据。

单个感知机只能形成线性边界，无法解决 XOR。MLP 将多次变换组合起来，逐层学习更复杂的表示。
![](Pasted%20image%2020261108172354.png)
## 神经网络如何学习

训练循环让模型根据误差**反复调整参数**，逐步改进预测。

一次迭代先前向传播得到预测，损失函数衡量误差。反向传播计算梯度，优化器更新参数，然后进入下一批数据。
![](Pasted%20image%2020261108172441.png)
## 激活函数

激活函数为网络加入**非线性**，使多层结构能够表示复杂关系。

若各层只有线性变换，叠再多层仍等价于一次线性变换。ReLU、Sigmoid、Tanh、GELU 等函数打破了这个限制。
![](Pasted%20image%2020261108172533.png)
## 损失函数

损失函数把预测偏差变成训练时可以**最小化的目标**。

回归常用 MSE，分类常用交叉熵。反向传播从 Loss 出发求梯度，优化器据此调整参数。
![](Pasted%20image%2020261109194455.png)

## 反向传播

反向传播计算参数对损失的影响，为权重更新**提供梯度**。

链式法则沿计算图反向传递局部变化率，得到每个参数的梯度。反向传播只计算梯度，优化器才真正修改参数。
![](Pasted%20image%2020261109194551.png)

## 梯度下降

梯度下降沿损失减小的方向**更新参数**。

梯度指向 Loss 上升最快的方向，参数沿相反方向更新。学习率决定步长：太小收敛慢，太大可能震荡。
![](Pasted%20image%2020261109194658.png)
## 优化器

优化器决定**怎样使用梯度更新参数**，影响收敛速度与稳定性。

SGD 用当前梯度，Momentum 保留历史方向。AdaGrad 和 RMSProp 自适应调整步长；Adam 综合两类思路，AdamW 解耦权重衰减。
![](Pasted%20image%2020261109194831.png)
## 训练好模型的两个关键

训练好模型，需要**稳定收敛**，也需要在新数据上可靠预测。

稳定性关注优化过程能否顺利下降；泛化性关注训练集以外的表现。只降低训练集 Loss 还不够。
![](Pasted%20image%2020261109195029.png)
## 学习率调度

学习率调度控制各阶段的**更新步长**，兼顾速度与稳定性。

Warmup 可先逐步提高学习率，之后再衰减。Step Decay 与 Cosine Annealing 提供不同的下降轨迹。
![](Pasted%20image%2020261109195137.png)
## 参数初始化

参数初始化为训练设置合适起点，帮助信号与梯度**稳定传播**。

同层权重完全相同会让神经元难以分工。随机权重还要控制尺度，Xavier/Glorot 与 He/Kaiming 适配不同激活函数。
![](Pasted%20image%2020261109195322.png)
## 归一化

归一化控制中间特征的尺度，让深层网络**更容易稳定训练**。

BatchNorm 使用同批样本的统计量，常用于 CNN。LayerNorm 在单个样本的特征维度计算统计量，因此常见于 Transformer。
![](Pasted%20image%2020261109195448.png)
## 泛化与过拟合

泛化能力衡量模型能否把学到的规律用在**未见过的数据**上。

训练集 Loss 下降而验证集 Loss 上升，是典型的过拟合信号。独立验证集帮助我们观察模型对新数据的表现。
![](Pasted%20image%2020261109195611.png)
## 正则化与权重衰减

正则化限制模型过度拟合训练集细节，帮助**改善泛化**。

L1 倾向于产生稀疏参数，L2 抑制较大权重。权重衰减直接缩小权重；AdamW 将其与梯度更新分开。
![](Pasted%20image%2020261109195706.png)
## Dropout

Dropout 随机关闭部分神经元，减少模型对**固定特征组合**的依赖。

每次迭代，部分神经元暂时不参与计算。网络因此在略有差异的子网络上训练，从而缓解过拟合。
![](Pasted%20image%2020261109195825.png)
## Early Stopping

Early Stopping 借助验证集决定**何时停训**，避免继续拟合噪声。

若验证集表现连续若干轮没有改善，就提前结束训练，并恢复验证集效果最好的参数。
![](Pasted%20image%2020261109195915.png)
## CNN 为什么适合图像

CNN 利用图像的局部结构与**参数共享**，高效识别视觉模式。

边缘和纹理具有局部性，同一模式又可能出现在不同位置。卷积核在空间上重复使用，减少参数量。
![](Pasted%20image%2020261109200035.png)
## 图像如何经过 CNN

CNN 逐层把边缘等低级特征组合成**可用于分类的物体表示**。

浅层提取边缘和颜色，深层逐步形成部件。池化或步幅卷积扩大感受野；残差连接帮助训练更深的网络。
![](Pasted%20image%2020261109200125.png)
## NLP 的发展脉络

NLP 模型把文本转成向量，并结合上下文完成**理解与生成**。

Token 和 Embedding 让文本可计算。RNN 按顺序传递信息，Attention 动态选择相关位置，Transformer 用自注意力建模上下文。
![](Pasted%20image%2020261109200247.png)
## Embedding

Embedding 将离散的 Token ID 映射为**可训练的连续向量**。

Token ID 本身不含语义。Embedding 矩阵 \(E \in \mathbb{R}^{V \times d}\) 为每个 ID 提供一行向量，训练会不断调整这些向量。
![](Pasted%20image%2020261109200349.png)
## RNN 的隐藏状态

RNN 用隐藏状态把已读内容带到下一时间步，处理**有顺序的输入**。

当前状态由输入 \(x_t\) 与前一状态 \(h_{t-1}\) 决定：\(h_t = f(x_t, h_{t-1})\)。同一个 RNN Cell 在各时间步共享参数。
![](Pasted%20image%2020261109200511.png)
## RNN 的时间展开

时间展开说明 RNN 如何复用参数，也揭示**长距离信息传递**的困难。

每一步接收当前输入与上一状态。最终状态可用于分类，但早期信息经过多步传递后容易衰减。
![](Pasted%20image%2020261109200557.png)
## LSTM 与 GRU

LSTM 和 GRU 用门控选择保留或遗忘的信息，缓解**长距离依赖**。

LSTM 增加 Cell State 和遗忘、输入、输出门；GRU 使用更简洁的更新门与重置门。两者都控制新旧信息如何流动。
![](Pasted%20image%2020261109200707.png)
## Seq2Seq

Seq2Seq 用编码器和解码器将输入序列转换为**可变长度的输出**。

Encoder 先编码输入，Decoder 再逐步生成目标序列。输入与输出长度可以不同，常用于翻译和摘要。
![](Pasted%20image%2020261109200744.png)
## 注意力机制

注意力机制让解码器按当前需要，**读取输入中最相关的位置**。

早期 Seq2Seq 只用一个固定向量承载输入，长序列容易丢失细节。Attention 在每一步计算权重，动态汇总相关位置。
![](Pasted%20image%2020261109200839.png)
## Transformer 自注意力

自注意力让序列中的每个位置汇集**可访问的上下文信息**。

Query 查找相关信息，Key 提供匹配依据，Value 承载内容。注意力权重决定当前位置应读取哪些信息。
![](Pasted%20image%2020261109201018.png)
## Transformer 的并行计算

矩阵化自注意力让已知序列的多个位置在训练时**并行计算**。

模型批量计算各位置的 Query、Key 和 Value，比 RNN 的时间步递推更适合 GPU；自回归生成仍逐 Token 进行。
![](Pasted%20image%2020261109201230.png)
## Transformer 架构

Transformer 用 Encoder 表示输入，Decoder 根据输入**逐步生成输出**。

Encoder 对输入做自注意力编码。Decoder 用因果掩码读取已有输出，再通过 Cross-Attention 读取 Encoder 表示。
![](Pasted%20image%2020261109201357.png)
## BERT、T5 与 GPT

BERT、T5 与 GPT 展示了 Transformer 如何适配**理解和生成任务**。

BERT 用 Encoder 构建双向表示。T5 用 Encoder-Decoder 做文本到文本转换。GPT 用 Decoder 预测下一个 Token。
![](Pasted%20image%2020261109201501.png)
## 大模型训练

大模型训练通过多个阶段，把基础生成能力转为**按指令工作**的能力。

预训练从大规模语料学习通用知识，指令微调提升指令遵循，偏好优化进一步调整回答质量。后两步属于后训练。
![](Pasted%20image%2020261109201650.png)
