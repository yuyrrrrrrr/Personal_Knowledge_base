# Transformer 前置概念回顾

## 标量、向量、矩阵与张量
![](../../../../image/Pasted%20image%2020261101111636.png)

| 名称       | 示例形式                    | 实际代表含义   |
| :------- | :---------------------- | :------- |
| **标量**   | `0.8`                   | 一个数值     |
| **向量**   | `[0.2, 0.8, 0.4, 0.6]`  | 一个 Token |
| **矩阵**   | 3×4 的二维数组（如 3 行 4 列的数值） | 一句话      |
| **三维张量** | 多个矩阵层叠                  | 一批句子     |
标量是一个数字，向量是一组有序数字，矩阵按行列组织数字，张量则可以继续扩展到更高维度。
- 在 Transformer 中，一个 `Token` 通常表示为**向量**，一句话组成**矩阵**，多句话组成的批次则表示为**三维张量**。
- 在 PyTorch 中，无论标量、向量、矩阵还是更高维数组，都统一使用 `Tensor` 表示。
## 加法、点积与矩阵乘法
![](../../../../image/Pasted%20image%2020261101112022.png)
> [!important] 核心总结
> - **加法**要求形状相同；
> - **点积**将两个等长向量变成一个标量分数；
> - **矩阵乘法**要求前一个矩阵的列数等于后一个矩阵的行数；
> - Attention 中的 $QK^T$ 正是通过转置让维度对齐，从而得到不同位置之间的匹配分数。

## Embedding：把离散符号变成有语义的向量
![](../../../../image/Pasted%20image%2020261101112756.png)
> [!info] 核心概念
> **Embedding 是模型中的可学习参数**。训练会不断调整词向量，使语义相近或关系相似的词在向量空间中呈现规律。

### 1. 从 Token 到稠密向量的流程
1. **Token**（如 "King"）转换为 **编号**（如 8）。
   * *注意：编号只是索引，用于从矩阵中取出该行，不是数值特征。*
2. 通过 **Embedding 矩阵**（在代码中表现为 `nn.Embedding(vocab_size, d_model)`，其中 `d_model` 例如 512）查找对应的行。
3. 输出 **稠密向量**（如 `[0.2, -0.7, 0.5, ...]`）。
4. 经过模型前向计算产生**训练损失**，反向传播**更新参数**。

### 2. 与 One-Hot 编码的对比

| 表示方式 | 特点 | 维度示例 | 信息密度 |
| :--- | :--- | :--- | :--- |
| **One-Hot** | 只有一位是 1，其余为 0 | `[50000]` | **高维稀疏** |
| **Embedding** | 全是浮点数 | `[512]` | **低维稠密** |

> [!success] 为什么使用 Embedding？
> 与高维稀疏的 One-Hot 相比，Embedding 使用更低维的稠密向量，能够承载更多语义信息。

### 3. 学习到的语义空间（Word2Vec 经典示例）
在训练好的向量空间中，词与词之间的关系可以通过向量运算表达：
$$
\text{King} - \text{Man} + \text{Woman} \approx \text{Queen}
$$
## Encoder-Decoder：一个负责理解，一个负责生成
![](../../../../image/Pasted%20image%2020261101113025.png)
> [!abstract] 核心思想
> **Encoder** 将输入转换成包含上下文信息的隐藏表示，**Decoder** 则以这些表示为条件，生成目标输出。

> [!info] 补充说明
> Encoder-Decoder 描述的是一种任务分工；下一页的 Seq2Seq，将具体展示它如何处理并生成两个序列。

## Seq2Seq：用一个序列生成另一个序列
![](../../../../image/Pasted%20image%2020261101113310.png)
> [!info] 编码阶段
> **输入序列**：`桌子` -> `底下` -> `有` -> `一只` -> `猫`
> **隐藏状态**：$h_1 \rightarrow h_2 \rightarrow h_3 \rightarrow h_4 \rightarrow h_5$
> **输出**：上下文向量 $c$

> [!success] 解码阶段
> **输入**：上下文向量 $c$
> **输出序列**：`<BOS>` -> `There` -> `is` -> `a` -> `cat` -> `under` -> `the` -> `table` -> `<EOS>`

---

**两大主要差异**：

| 差异类型     | 示例对比                        |
| :------- | :-------------------------- |
| **长度不同** | `5` -> `7`                  |
| **语序不同** | `桌子底下` -> `under the table` |

> [!important] 核心结论
> - Seq2Seq 不是逐词替换，而是先编码完整输入，再生成长度和顺序都可能不同的新序列。
> - Decoder 从 `<BOS>` 开始逐步预测下一个 Token，直到输出 `<EOS>`。

## Attention：生成不同的词，动态关注不同的位置
![](../../../../image/Pasted%20image%2020261101113443.png)
> [!important] 核心区别
> 传统 Seq2Seq 始终依赖同一个固定上下文向量，**Attention 则允许 Decoder 在每个生成时刻重新关注全部 Encoder 隐藏状态**。
> 
> 例如，生成「深度」时，模型给予 `deep` 更高权重；生成其他词时，注意力权重也会随之改变。
## Softmax：把任意分数变成概率分布
![](../../../../image/Pasted%20image%2020261101113556.png)

> [!important] 核心总结
> **Softmax 不负责产生分数**，而是把一组任意实数转换为**非负、总和为 1 的分布**。
> - 在 Attention 中，它产生**注意力权重**；
> - 在 Decoder 输出端，它产生下一个 **Token 的概率**。

## 线性变换：用可学习的矩阵重新组织信息
![](../../../../image/Pasted%20image%2020261101113728.png)

> [!important] 核心总结
> 线性变换通过可学习的权重矩阵，对输入向量进行缩放、旋转、组合或升降维。
> Transformer 正是利用不同的线性变换，从同一输入中得到了 $Q$、$K$、$V$ 等不同的表示，从而让模型能从不同维度去理解信息。

## 激活函数：让网络学会非线性关系
![](../../../../image/Pasted%20image%2020261101114037.png)
连续堆叠线性变换仍然只是线性变换（等价于一层），决策边界始终是一条直线，模型无法表示复杂的非线性关系。
激活函数在两层线性变换之间加入**转折**，打破了纯线性变换的局限，使 FFN（前馈神经网络）具有更强的表达能力。
## FFN：让每个 Token 独立加工信息
![](../../../../image/Pasted%20image%2020261101114512.png)
**核心计算逻辑**：
相同参数，逐 Token 独立计算。
$$
\text{FFN}(x) = W_2\sigma(W_1x + b_1) + b_2
$$
**维度变化过程**：
$$
 d_{model} \rightarrow d_{ff} \rightarrow d_{model} 
$$
$$
 512 \rightarrow 2048 \rightarrow 512 
$$

> [!important] 核心总结
> - **FFN 对序列中的每个 Token 使用同一组参数，但各个位置之间互不交换信息。**
> - 它先扩展维度并加入非线性，再压回 `d_model`，为每个 Token 提炼更丰富的特征。
## 残差连接：为信息保留一条捷径
![](../../../../image/Pasted%20image%2020261101114633.png)
> [!important] 核心作用
> - 残差连接把子层计算结果 $F(x)$ 与原始输入 $x$ 相加，让网络只需学习需要**补充的变化**。
> - 它既能**保留原始信息**，也为反向传播提供**更短的路径**，使深层 Transformer 更容易训练。

## 归一化：让每个 Token 的数值更稳定
![](../../../../image/Pasted%20image%2020261101114827.png)

1. **稳定数值尺度**：LayerNorm 对**每个 Token** 的特征维度独立归一化，使不同位置的数值尺度保持稳定。
    
2. **保留表达能力**：归一化之后还有可学习的 γγ 和 ββ，因此模型仍然可以恢复适合任务的缩放与偏移。
