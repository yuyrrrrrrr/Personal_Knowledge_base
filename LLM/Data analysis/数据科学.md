标准工作流程的六个核心步骤: 问题定义, 数据收集, 数据清洗, 探索性数据分析, 建模, 部署和监控

问题定义是第一部, 要明确业务目标和数据科学目标. 比如业务目标是"降低用户流失", 转化成数据科学目标就是"预测哪些用户可能流失". 清晰的问题定义决定了后续工作的方向

数据收集是获取分析所需的数据. 可能来自数据库, API, 文件, 爬虫等. 要确保数据质量和数量满足需求, 数据不够就要补充采集.

数据清洗通常占整个项目60%-80%的时间. 处理缺失值, 异常值, 重复值, 统一数据格式, 处理不一致的数据. 脏数据会导致错误的分析结果, 这一步必须认真对待

探索性数据分析 (EDA) 是理解数据的过程. 通过统计分析和可视化, 了解数据分布, 发现异常, 理解变量关系. EDA 的洞察会指导特征工程和模型选择

建模阶段包括特征工程, 模型选择, 训练, 评估, 调优. 这是技术含量最高的环节, 需要尝试不同算法, 调整参数, 指导找到最优模型.

部署和监控时把模型投入生产使用, 监控模型性能, 定期重新训练. 模型不是一劳永逸的, 数据分布会变化, 模型会衰减, 要持续维护.

1. 迭代而非线性
	六个步骤并非严格线性. EDA 可能发现数据问题,又要回到清洗环节. 建模效果不好, 可能要重新做特征工程. 部署后发现问题, 要重新建模. 数据科学史迭代的过程, 要灵活调整, 不要死板地按步骤走. 经验丰富的数据科学家, 会在各个环节间快速切换, 找到最优解.
2. 不同角色分工
	在大公司, 这六个步骤可能由不同角色完成. 数据工程师负责数据收集和清洗, 搭建数据管道. 数据分析师负责 EDA, 提供业务洞察. 数据科学家/算法工程师负责建模. 机器学习工程师负责模型部署和优化. 小公司或创业团队, 数据科学家可能要全包. 理解分工, 才能找准自己的定位.
3. 业务理解的重要性
	技术很重要, 但业务理解更重要. 如果不懂业务, 可能定义错问题, 选错指标, 做出不实用的模型. 要多和业务人员沟通, 理解业务逻辑, 痛点, 目标. 要懂领域知识, 金融, 医疗, 电商的数据特点不同, 处理方法也不同. 技术 + 业务, 才能成为优秀的数据科学家

先记主线：**pandas 管表格语义，NumPy 管数值计算，Matplotlib 管视觉验证**。三者通过 `DataFrame → ndarray → Figure/Axes` 连接

## 一、NumPy：数值计算底座

NumPy (Numerical Python) 是Python 的科学计算基础库, 提供了高性能的多维数组对象和数学运算函数, 是几乎所有数据科学库的基础.

NumPy 的核心是 ndarray (N 维数组) , 它是固定类型的多维数组, 比 Python 原生的list 快几十倍. ndarray 在内存中连续存储, 能利用 CPU 的向量化指令, 而且底层用C实现, 性能接近原生代码.

NumPy 的主要功能包括: 数组创建和操作, 支持各种方式创建数组 (zeros, ones, arange, linspace) . 数学运算, 提供大量数学函数 (sin, cos, exp, log) 和运算符重载 (+, -, *, /). 广播机制, 让不同形状的数组能自动对齐运算. 线性代数, 提供矩阵运算, 求逆, 特征值分解等. 随机数生成, 支持各种概率分布.

1. 向量化的性能优势
	NumPy 的向量化操作比Pyhton循环快几十倍甚至上百倍. 比如计算所有元素的平方, 用 arr* 2 比用 for 循环快 50 - 100 倍 .这是因为向量化操作在底层是C代码的循环, 而且能利用SIMD指令并行计算. 数据科学中要尽量用向量化操作, 避免Pyhon循环
2. 广播机制的理解
	广播让不同形状的数组能一起运算, NumPy 会自动拓展维度. 比如 (3,1)的数组和 (1,4) 的数组相加, 会广播成(3,4). 广播规则是从右向左对齐维度, 维度为1的会被复制. 理解广播能写出简洁高效的代码, 避免显示循环和复制数据.
3. NumPy 和 Pandas 的关系
	Pandas 是建立在 NumPy之上的, DataDrame底层就是NumPy数组. 理解NumPy有助于理解 Pandas. 有些操作 NumPy更快 (如纯数值计算), 有些Pandas 更方便 (如处理混合类型数据, 分组聚合). 两者配合使用, NumPy处理底层数组, Pandas处理高层数据结构.

### 必须掌握的 5 件事

1. **核心对象是 `ndarray`**
    数组元素通常必须是同一类型，形状必须规则，不能像 Python 列表一样锯齿化。

2. **先看 `shape`、`dtype`，再写计算**
    机器学习中最常见的是：

    - `X.shape = (n_samples, n_features)`
    - `y.shape = (n_samples,)`
    - 单个样本常写成 `(n_features,)`，批量预测时可能需要 `(1, n_features)`
3. **理解 `axis`**
    对聚合函数，可以把 `axis` 理解成“被压缩掉的那个维度”：

    - `axis=0`：压缩行，得到每列统计量。
    - `axis=1`：压缩列，得到每行统计量。
4. **切片通常是视图**
    NumPy 切片通常不复制数据。修改切片可能改变原数组；确实需要独立数据时使用 `.copy()`。

5. **优先向量化，避免逐元素循环**
    线性预测、均方误差、标准化等都可以直接写成数组表达式。


```python
import numpy as np

X = np.array([[1., 2.],
              [3., 4.],
              [5., 6.]])

print(X.shape)           # (3, 2)
print(X.mean(axis=0))    # 每列均值，shape (2,)
print(X.mean(axis=1))    # 每行均值，shape (3,)

w = np.array([0.5, 2.0])
y_pred = X @ w

y = np.array([3., 8., 13.])
mse = np.mean((y_pred - y) ** 2)
print(mse)
```

### 注意事项

- `(n,)`、`(n, 1)`、`(1, n)` 形状不同，不能混着用。
- 整数数组与浮点数组混合运算时，会进行类型提升。
- 含字符串和数字的数组可能变成低效的 `object`。
- 新代码优先使用 `rng = np.random.default_rng(42)`，方便复现。
- `np.empty()` 不是空数组，内容未初始化。

## 二、pandas：把原始表格变成可信数据

Pandas是Python 的数据处理库, 提供了高效的数据结构和数据分析工具, 是数据科学家处理表格数据的首选工具.
Pandas 有两个核心数据结构: Series 和 DataFrame.

Serise 是一维数据结构, 类似带标签的数组, 有索引(index) 和值(values).
可以理解为Excel 的一列数据, 或者字典. Series 适合存储单一变量的数据, 如一列数字, 一列字符串.

DataFrame 是二维表格数据结构, 由多个Series组成, 类似Excel表格或SQL表. 每一列是一个Series, 有列名.  每一行有索引. DataFrame 是Pandas最常用的数据结构, 能处理混合类型的数据, 支持丰富的操作 (筛选, 分组, 聚合, 合并等).

1. Pandas 的强大数据操作
	Pandas提供了几百个方法来处理数据. 读取数据 (read_csv, read_excel, read_sql), 筛选数据 (条件索引, loc, iloc), 数据清洗 (fillna, dropna, replace), 数据转换 (apply, map), 数据聚合 (groupby, pivot_table), 数据合并 (merge, concat, join). 这些操作覆盖了数据处理的方方面面, 熟练掌握能大幅提升工作效率
2. DataFrame 的性能特点
	DataFrame 虽然方便, 但不如 NumPy 快. 对于纯数值计算, NumPy 数组更快. DataFrame 的优势是能处理混合类型, 有列名, 操作更直观. 实际使用中, 可以组合使用: 用DataFrame 做数据清洗和转换, 提取数值列转成NumPy 数组做计算, 再转回 DataFrame. 这种混合使用既方便又高效.
3. Pandas 的内存优化
	大数据集用 Pandas 可能内存不够. 优化方法包括: 指定数据类型 (int8 代替 int64 节省内存), 分块读取(chunksize 参数), 只读取需要的列, 用 category 类型存储重复值多的列. 还可以用Dask, Vaex 等库处理超大数据, 它们是 Pandas 的分布式或内存优化版本.

### 必须掌握的 5 件事

1. **`Series` 是一列，`DataFrame` 是表**
    `df["score"]` 返回 Series；`df[["score"]]` 返回只有一列的 DataFrame。

2. **读数据后先检查，不要先清洗**
    建议顺序：形状、类型、缺失、重复、统计摘要、样本抽查。

3. **用 `loc`、`iloc`、布尔筛选明确选择数据**

    - `loc`：按标签，切片端点通常包含。
    - `iloc`：按整数位置，切片端点不包含。
    - `at` / `iat`：快速取单个标量。
4. **缺失值和类型处理是业务决策**
    不要机械用均值填充。要判断缺失机制，并确保训练集、验证集和测试集使用同一套处理规则。
    缺失值 (Missing Values) 是数据清洗中最常见的问题, 处理方法要根据数据特点和业务需求选择.
    常见的处理方法有删除, 填充, 预测三大类.

    删除法最简单, 直接删除包含缺失值的行和列. 如果缺失值很少 (< 5%), 删除影响不大. 如果某列大部分是缺失值, 可以删除整列. 但删除会损失信息, 要谨慎使用.

    填充法用特定值替代缺失值. 数值类型数据可以用均值, 中位数, 众数填充. 均值容易受异常值影响, 中位数更稳健. 类别型数据可以用众数或新类别 (如"未知")填充. 时间序列数据可以用前向填充 (用前一个值) 或后向填充 (用后一个值).

    预测法用机器学习模型预测缺失值. 把有缺失值的列作为目标, 其他列作为特征, 训练模型预测. 这种方法最复杂但效果可能最好, 特别是缺失值有规律的情况.

```python
    import pandas as pd

df = pd.DataFrame({
    '年龄': [25, None, 30, None, 35],
    '收入': [5000, 6000, None, 8000, 9000],
    '城市': ['北京', '上海', None, '深圳', '广州']
})

# 检测缺失值
df.isnull()
df.isnull().sum()  # 每列的缺失值数量

# 删除法
df.dropna()  # 删除有缺失值的行
df.dropna(axis=1)  # 删除有缺失值的列

# 填充法
df.fillna(0)  # 用 0 填充
df['年龄'].fillna(df['年龄'].mean())  # 用均值填充
df['城市'].fillna('未知')  # 用固定值填充
df.ffill()  # 前向填充（时间序列）

```

- 缺失值的类型
	缺失值有三种类型. 完全随机缺失 (MCAR), 缺失和任何变量无关, 随机发生. 随机缺失(MAR), 缺失和模型观测变量相关, 但和缺失变量本身无关. 非随机缺失(MNAR), 缺失和缺失值本身相关, 比如收入高的人不愿意填收入. 不同类型的缺失值处理方法不同, MCAR 可以随意处理, MNAR 要小心, 简单填充可能引入偏差.
- 填充值的选择
	均值填充简单但会减小方差, 影响数据分布. 中位数对异常值鲁棒, 适合有偏分布. 众数适合类别数据. 也可以用插值方法 (线性插值, 多项式插值), 适合有趋势的数据. 选择哪种方法要看数据特点和对模型的影响, 可以对比不同方法的效果.
- 缺失值的指示变量
	有时候缺失本身是有信息的. 比如用户不填收入, 可能是隐私意识强或收入特别高. 可以创建指示变量 (is_missing), 标记哪些值原本是缺失的. 在建模时把指示变量也作为特征, 模型能学到缺失的模式. 这种技巧在某些场景能提升模型效果.


5. **`groupby`、`merge`、`pivot_table` 是特征工程主力**
    它们把明细数据转换成按用户、时间或类别汇总的特征表。


```python
import pandas as pd

df = pd.DataFrame({
    "city": ["A", "A", "B", "B"],
    "income": [10, 12, 8, 11],
})

print(df.dtypes)
print(df.isna().sum())
print(df.loc[df["income"] > 10, ["city", "income"]])
print(df.groupby("city")["income"].mean())
```

### 注意事项

- 避免链式赋值，例如 `df[mask]["x"] = 1`。使用 `df.loc[mask, "x"] = 1`。
- `merge` 前检查连接键的类型、空值和唯一性。
- 多对多连接可能让行数意外膨胀。
- 变量编码、缺失值填充、标准化规则只能在训练集上拟合。
- 行索引和业务 ID 通常不是模型特征，除非有明确语义。

## 三、Matplotlib：用图发现和验证

数据可视化是将数据用图表,图形等视觉形式展示出来, 让抽象的数字变得直观易懂. 一张好的图表胜过千言万语, 能快速传达数据的规律和洞察.

数据可是还在数据科学中有三个核心作用. 探索数据时, 通过可视化能快速发现数据分布, 异常点, 变量关系, 指导后续分析. 分析过程中, 可视化帮助验证假设, 比较结果. 展示结果时, 可视化能让非技术人员也能理解数据结论, 促进决策.

Python 常用的可视化库有:

Matplotlib 是最基础的绘图库, 功能全面, 几乎能画任何图表, 但代码稍微繁琐. 适合需要精确控制图表细节的场景.

Seaborn 是基于 Matplotlib 的统计可视化库, API更简洁, 默认样式更美观. 擅长统计图表(箱线图, 热力图, 分布图), 几乎代码就能画出专业图表.

Plotly 是交互式可视化库, 生成的图表可以缩放, 悬停查看数据, 导出图片. 适合数据探索和展示, 网页端体验好.

常见图表类型:
- 散点图: 查看变量关系, 异常点
- 柱状图: 对比类别数据
- 折线图: 展示趋势变化
- 箱线图: 展示数据分布和异常值
- 热力图: 展示相关性矩阵

```python
import matplotlib.pyplot as plt
import seaborn as sns

# Matplotlib 散点图
plt.scatter(x, y)
plt.xlabel('X轴')
plt.ylabel('Y轴')
plt.title('散点图')
plt.show()

# Seaborn 热力图
sns.heatmap(df.corr(), annot=True, cmap='coolwarm')
plt.show()

```

1. 选择合适的图表类型
	不同数据关系适合不同图表. 比较数值用柱状图, 展示趋势用折线图, 展示分布用直方图或箱线图, 展示关系用散点图,展示占比用饼图. 选错图表可能误导读者. 要累计每种图表的使用场景, 选择最能表达数据含义的类型.
2. 可视化的最佳实践
	好的可视化要简洁明了, 不要包含过多信息.要有清晰的标题和坐标轴标签. 颜色使用要合理,避免过于花哨. 要考虑色盲友好, 不要只用红绿区分. 数据点不要太密集, 必要时聚合或采样. 这些细节虽小, 但影响图表的可读性和专业度.
3. 交互式可视化的优势
	静态图表只能展示固定视角, 交互式图表让用户能探索数据. Plotly, Bokeh 等库能生成交互式图表, 用户可以缩放, 筛选, 查看详细数据. 在数据展示和汇报时, 交互式图表能让观众更深入地理解数据. 但交互式图表文件大, 加载慢, 要权衡使用.

### 必须掌握的 5 件事

1. **分清 `Figure`、`Axes`、`Axis`**

    - Figure：整张画布。
    - Axes：实际绘图区域。
    - Axis：x 轴或 y 轴。
2. **正式代码优先使用 OO 风格**
    `fig, ax = plt.subplots()` 比依赖全局 pyplot 状态更清晰，尤其适合函数、循环和多子图。

3. **机器学习常用图要能准确选择**

    - 数值分布：直方图、箱线图。
    - 特征关系：散点图。
    - 类别比较：柱状图。
    - 时间趋势：折线图。
    - 矩阵和图像：`imshow`、`pcolormesh`。
4. **每张图必须有标题、坐标轴和单位**
    图不是装饰。它必须回答一个具体问题，例如“是否存在异常值”。

5. **保存图用 `savefig()`**
    在 `show()` 前保存，或保留 Figure 对象后再保存。


```python
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(7, 4), layout="constrained")

ax.scatter(x, y, label="data")
ax.plot(x, y_pred, color="C1", label="model")
ax.set_title("Observed vs predicted")
ax.set_xlabel("feature")
ax.set_ylabel("target")
ax.legend()

fig.savefig("result.png", dpi=160, bbox_inches="tight")
plt.show()
```

### 注意事项

- 量纲差异很大时，不要硬塞到一个普通坐标轴。
- 连续、发散、分类数据应使用不同 colormap。
- 类别过多时优先分面或分组，不要制造彩虹图。
- 批量循环画图时使用 `plt.close(fig)` 释放资源。
- 图表能暴露问题，但不能替代交叉验证和统计检查。


## 描述性统计统计的常用指标有哪些? 如何计算?
描述性统计式用数字指标概括和描述数据的基本特征, 主要包括集中趋势, 离散程度, 分布形态三类指标.

集中趋势指标描述数据的中心位置. 均值 (Mean) 是所有数据的平均值, 最常用但容易受异常值影响. 中位数 (Median) 是排序后中间位置的值, 对异常值鲁棒. 众数 (Mode) 是出现最频繁的值, 适合类别数据.

离散程度指标描述数据的分散情况. 极差 (Range) 是最大值减最小值, 简单但粗糙. 方差 (Variance) 是每个数据点与均值的偏差平方的平均值, 翻译数据的波动. 标准差 (Standard Deviation) 是方差的平方根, 和原数据同单位, 更直观. 四分位数 (Quartile) 将数据分成四份, Q1, Q2 (中位数), Q3 是关键点.
分布形态指标描述数据的分布特征, 偏度 (Skewness) 描述分布的对称性, 正偏表示右尾长, 负偏表示左尾长. 峰度 (Kurtosis) 描述分布的尖锐程度.

## 拓展
1. 均值和中位数的选择
	均值容易受极端值影响, 不适合有异常值的数据. 中位数更稳健, 适合有偏分布.比如收入数据, 少数高收入者会拉高均值, 中位数更能反映普通人的收入水平. 在数据探索阶段, 要同时看均值和中位数,  如果差异大, 说明有异常值或分布不对称, 要进一步分析.
2. 标准差的业务含义
	标准差反映数据的波动性. 股票收益率的标准差大, 说明波动大, 风险高. 用户活跃度的标准差大, 说明用户行为差异大, 需要分群运营. 理解标准差的业务含义, 能从数据中得出更有价值的洞察. 在机器学习中, 标准差也用于特征标准化 (StandardScaler),让不同尺度的特征可比.
3. 箱线图的解读
	箱线图 (Box Plot) 是可视化描述性统计的好工具. 箱体表示 Q1 到 Q3 的范围 (包含50% 的数据), 箱内的线是中位数. 箱体外的"须"延伸到1.5倍IQR (四分位距) 的范围.超出须的点是异常值. 通过箱线图能快速看出数据的分布, 中心, 离散程度和异常值, 是EDA 的常用工具.

什么是正态分布? 为什么它在数据科学中重要?

正态分布(Normal Distribution), 也叫高斯分布, 是统计学中最重要的概率分
布,呈现经典的钟形曲线,对称分布在均值两侧。

正态分布由两个参数决定:均值 (μ) 决定中心位置,标准差 (σ) 决定曲线的宽
窄。正态分布的特点是 68%的数据在均值 ±1 个标准差范围内, 95%在 ±2 个标
准差内, 99.7%在 ±3 个标准差内,这叫 “68-95-99.7规则”。

正态分布在数据科学中极其重要,原因有几个。首先是自然界和社会现象很多都服
从或近似服从正态分布, 如身高、体重、测量误差、考试成绩。其次是中心极限定
理, 大量独立随机变量的和会趋向正态分布, 这让正态分布成为统计推断的基础。
第三是很多机器学习算法假设数据服从正态分布, 如线性回归假设误差服从正态分
布。

正态分布还是很多统计检验的基础。t检验、z检验、方差分析等都基于正态假
设。异常值检测常用"3σ原则”: 超出均值 ±3 个标准差的点视为异常。

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

# 生成正态分布数据
data = np.random.normal(loc=0, scale=1, size=1000)  # 均值0，标准差1

# 验证正态性
stats.normaltest(data)  # 正态性检验

# 绘制正态分布曲线
x = np.linspace(-4, 4, 100)
y = stats.norm.pdf(x, 0, 1)  # 概率密度函数
plt.plot(x, y)
plt.show()

```

## 扩展知识

1)正态性检验的方法

实际数据不一定服从正态分布, 要先检验。可视化方法是画Q-Q图 (Quantile-Quantile
Plot), 数据点在直线上说明接近正态。统计检验方法有Shapiro-Wilk检验、K-S检验, p值大
于 0.05 说明符合正态分布。如果数据不是正态分布,有些统计方法就不适用,要用非参数方法或
对数据做转换(如取对数)。

2)标准正态分布和Z分数

标准正态分布是均值为0、标准差为1的正态分布。任何正态分布都可以通过标准化转换成标准正
态分布: Z = (X-μ) / σ。Z分数表示数据点距离均值多少个标准差, 可以比较不同尺度的数据。
比如身高 180cm 的Z分数是1.5, 体重 70kg的Z分数是 0.8, 说明这个人身高比体重更突出。

3)正态分布的局限性

不是所有数据都是正态分布。收入、财富通常是幂律分布 (少数人占大部分)。网站访问量是长尾
分布。点击率、转化率是二项分布。盲目假设正态分布会导致错误结论。要先探索数据分布,选择
合适的分布模型。对于非正态数据, 可以用对数转换、Box-Cox转换等方法转成近似正态,但要注
意转换后的解释性。

## 数据科学中如何处理异常值?
异常值(Outliers)是偏离数据整体分布的极端值,可能是测量错误、数据录入错误,也可能是真实存在的特殊情况。处理异常值要先判断是否真的异常,再决定如何处理。

检测异常值的常用方法有统计法和可视化法。统计法包括 3σ 原则 (超出均值 ±3 倍标准差)、四分位距法 (IQR,超出Q1-1.5IQR或Q3+1.51QR)、Z分数法(|Z|>3)。可视化法是用箱线图、散点图直观发现异常点。

处理异常值有几种策略。删除法直接删除异常值,简单但损失信息, 适合异常值确实是错误的情况。替换法用均值、中位数或边界值替换, 保留数据量但可能引入偏差。分箱法将连续值离散化, 异常值和正常值归入不同区间,降低异常值影响。变换法用对数、平方根等转换压缩异常值的影响。保留法如果异常值有业务意义(如高价值客户), 就保留, 但在建模时要注意它们的影响。

```python
import pandas as pd
import numpy as np

data = pd.Series([10, 12, 11, 13, 100, 14, 15, 12])

# 1. IQR 方法检测异常值
Q1 = data.quantile(0.25)
Q3 = data.quantile(0.75)
IQR = Q3 - Q1
lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR

outliers = data[(data < lower_bound) | (data > upper_bound)]
print(f"异常值: {outliers.values}")  # [100]

# 2. 删除异常值
clean_data = data[(data >= lower_bound) & (data <= upper_bound)]

# 3. 替换异常值
data_capped = data.clip(lower_bound, upper_bound)  # 截断到边界值

```

## 扩展知识

1)异常值的业务判断

技术上的异常值不一定是业务上的异常。比如电商数据中,一个订单金额10万,统计上是异常值,但可能是真实的大客户订单。删除这样的数据会丢失重要信息。所以要结合业务判断,真正的错误数据才删除或修正,有业务意义的异常值要保留。可以分开处理,如单独建模高价值客户。

2)异常值对模型的影响

不同模型对异常值的敏感度不同。线性回归、K近邻对异常值敏感,异常值会显著影响模型。决策树、随机森林对异常值相对鲁棒。深度学习如果数据量够大,异常值的影响会被稀释。选择模型时要考虑数据中异常值的情况,或者在数据预处理时就处理好异常值。

3)异常值检测算法

除了统计方法,还有专门的异常检测算法。lsolation Forest 通过隔离异常点来检测。LOF(LocalOutlier Factor)基于密度检测局部异常。One-Class SVM学习正常数据的边界。这些算法能处理更复杂的异常情况,如多维空间的异常、局部异常。在实际项目中,可以组合多种方法,提高异常检测的准确性。
