## AIAgent全链路流程

```markdown
┌─────────────────────────────────────────────────────────────────────┐
│ 【用户层】 Prompt / API 调用                                          │

                                ↓

│ 【大模型网关层】                                                      │
```

在经过两天的调研以及采访相关从业人员之后，我大概率是会放弃，因为这条业务线的沉没成本太高了。

有几个特别难的门槛：

1. 公司内部转岗只能转到CANN算子这个岗位去，不可能直接让你去做硬件的，因为跟以往工作经历可以说是毫无关联。然而这个岗位在问过人之后，也很容易被大模型替代。大模型现在写算子的水平，可以参考看一下Deepseek研究员那篇文章。大模型写得会比很多资深研究员还好；
2. 学习曲线太陡峭了。问了好几个人，光上手，要成为一个成熟的开发，就需要1~2年；
3. 公司内部转岗会非常困难，因为我们部门也非常缺人，让我们领导同意放人几乎不可能；
